Ejercicio 2.3

Objetivos:

  • Iterar como un profesional

Archivos modificados: Ninguno.

La iteración es una habilidad esencial de Python. En este ejercicio, veremos una serie de expresiones idiomáticas de iteración comunes.

Comience el ejercicio tomando algunas filas de datos de un archivo CSV.

>>> import csv
>>> f = open('Data/portfolio.csv')
>>> f_csv = csv.reader(f)
>>> headers = next(f_csv)
>>> headers
['name', 'shares', 'price']
>>> rows = list(f_csv)
>>> from pprint import pprint
>>> pprint(rows)
[['AA', '100', '32.20'],
 ['IBM', '50', '91.10'],
 ['CAT', '150', '83.44'],
 ['MSFT', '200', '51.23'],
 ['GE', '95', '40.37'],
 ['MSFT', '50', '65.10'],
 ['IBM', '100', '70.44']]
>>>

(a) Iteración básica y desempaquetado

La instrucción for itera sobre cualquier secuencia de datos. Por ejemplo:

>>> for row in rows:
        print(row)

['AA', '100', '32.20']
['IBM', '50', '91.10']
['CAT', '150', '83.44']
['MSFT', '200', '51.23']
['GE', '95', '40.37']
['MSFT', '50', '65.10']
['IBM', '100', '70.44']
>>>

Descomprima los valores en variables separadas si lo necesita:

>>> for name, shares, price in rows:
        print(name, shares, price)

AA 100 32.20
IBM 50 91.10
CAT 150 83.44
MSFT 200 51.23
GE 95 40.37
MSFT 50 65.10
IBM 100 70.44
>>>

Es bastante común usar _ o __ como una variable descartable si no le interesa uno o más de los valores. Por ejemplo:

>>> for name, _, price in rows:
        print(name, price)

AA 32.20
IBM 91.10
CAT 83.44
MSFT 51.23
GE 40.37
MSFT 65.10
IBM 70.44
>>>

Si no sabe cuántos valores se están descomprimiendo, puede usar * como comodín. Pruebe este experimento para agrupar los datos por nombre:

>>> from collections import defaultdict
>>> byname = defaultdict(list)
>>> for name, *data in rows:
        byname[name].append(data)

>>> byname['IBM']
[['50', '91.10'], ['100', '70.44']]
>>> byname['CAT']
[['150', '83.44']]
>>> for shares, price in byname['IBM']:
        print(shares, price)

50 91.10
100 70.44
>>>

(b) Conteo con enumerate()

enumerate() es una función útil si alguna vez necesita mantener un contador o índice mientras itera. Por ejemplo, supongamos que desea un número de fila adicional:

>>> for rowno, row in enumerate(rows):
        print(rowno, row)

0 ['AA', '100', '32.20']
1 ['IBM', '50', '91.10']
2 ['CAT', '150', '83.44']
3 ['MSFT', '200', '51.23']
4 ['GE', '95', '40.37']
5 ['MSFT', '50', '65.10']
6 ['IBM', '100', '70.44']
>>>

Puede combinar esto con el desempaquetado si tiene cuidado con la forma en que lo estructura:

>>> for rowno, (name, shares, price) in enumerate(rows):
        print(rowno, name, shares, price)

0 AA 100 32.20
1 IBM 50 91.10
2 CAT 150 83.44
3 MSFT 200 51.23
4 GE 95 40.37
5 MSFT 50 65.10
6 IBM 100 70.44
>>>

(c) Uso de la función zip()

La función zip() se utiliza con mayor frecuencia para emparejar datos. Por ejemplo, recuerda que creaste una variable headers:

>>> headers
['name', 'shares', 'price']
>>>

Esto podría ser útil para combinar con los otros datos de fila:

>>> row = rows[0]
>>> row
['AA', '100', '32.20']
>>> for col, val in zip(headers, row):
        print(col, val)

name AA
shares 100
price 32.20
>>>

O tal vez puedas usarlo para hacer un diccionario:

>>> dict(zip(headers, row))
{'name': 'AA', 'shares': '100', 'price': '32.20'}
>>>

O tal vez una secuencia de diccionarios:

>>> for row in rows:
        record = dict(zip(headers, row))
        print(record)

{'name': 'AA', 'shares': '100', 'price': '32.20'}
{'name': 'IBM', 'shares': '50', 'price': '91.10'}
{'name': 'CAT', 'shares': '150', 'price': '83.44'}
{'name': 'MSFT', 'shares': '200', 'price': '51.23'}
{'name': 'GE', 'shares': '95', 'price': '40.37'}
{'name': 'MSFT', 'shares': '50', 'price': '65.10'}
{'name': 'IBM', 'shares': '100', 'price': '70.44'}
>>>

(d) Expresiones de generador

Una expresión de generador es casi exactamente lo mismo que una comprensión de lista, excepto que no crea una lista. En cambio, crea un objeto que produce los resultados de forma incremental, generalmente para su consumo por iteración. Pruebe un ejemplo simple:

>>> nums = [1,2,3,4,5]
>>> squares = (x*x for x in nums)
>>> squares
<generator object <genexpr> at 0x37caa8>
>>> for n in squares:
        print(n)

1
4
9
16
25
>>>

Notará que una expresión de generador solo se puede usar una vez. Observa lo que sucede si realizas el bucle for nuevamente:

>>> for n in squares:
        print(n)

>>>

Puedes obtener manualmente los resultados uno a la vez si usas la función next(). Prueba esto:

>>> squares = (x*x for x in nums)
>>> next(squares)
1
>>> next(squares)
4
>>> next(squares)
9
>>>

Sigue escribiendo next() para ver qué sucede cuando no hay más datos.

Si la tarea que estás realizando es más complicada, aún puedes aprovechar los generadores escribiendo una función de generador y usando la declaración yield en su lugar. Por ejemplo:

>>> def squares(nums):
        for x in nums:
            yield x*x

>>> for n in squares(nums):
        print(n)

1
4
9
16
25
>>>

Volveremos a las funciones generadoras un poco más adelante en el curso. Por ahora, solo considere estas funciones como si tuvieran la interesante propiedad de introducir valores en la instrucción for.

(e) Expresiones generadoras y funciones de reducción

Las expresiones generadoras son especialmente útiles para introducir datos en funciones como sum(), min(), max(), any(), etc. Pruebe algunos ejemplos utilizando los datos de cartera de antes. Observe con atención que a estos ejemplos les faltan algunos corchetes adicionales ([]) que aparecieron al utilizar listas por comprensión.

>>> from readport import read_portfolio
>>> portfolio = read_portfolio('Data/portfolio.csv')
>>> suma(s['shares']*s['price'] para s en la cartera)
44671.15
>>> min(s['shares'] para s en la cartera)
50
>>> any(s['name'] == 'IBM' para s en la cartera)
True
>>> all(s['name'] == 'IBM' para s en la cartera)
False
>>> suma(s['shares'] para s en la cartera si s['name'] == 'IBM')
150
>>>

A continuación se muestra un uso sutil de una expresión de generador para generar valores separados por comas:

>>> s = ('GOOG',100,490.10)
>>> ','.join(s)
... observe que falla...
>>> ','.join(str(x) for x in s) # Esto funciona
'GOOG,100,490.1'
>>>

La sintaxis de los ejemplos anteriores requiere algo de práctica, pero el punto crítico es que ninguna de las operaciones crea una lista completa de resultados. Esto le permite ahorrar mucha memoria. Sin embargo, debe asegurarse de no excederse con la sintaxis.

(f) Ahorro de mucha memoria

En el Ejercicio 2.1 escribió una función read_rides_as_dicts() que lee los datos del bus CTA en una lista de diccionarios. Su uso requiere mucha memoria. Por ejemplo, busquemos el día en el que el autobús de la ruta 22 tuvo el mayor número de pasajeros:

>>> import tracemalloc
>>> tracemalloc.start()
>>> import readrides
>>> rows = readrides.read_rides_as_dicts('Data/ctabus.csv')
>>> rt22 = [row for row in rows if row['route'] == '22']
>>> max(rt22, key=lambda row: row['rides'])
{'date': '06/11/2008', 'route': '22', 'daytype': 'W', 'rides': 26896}
>>> tracemalloc.get_traced_memory()
... mira el resultado. Debería rondar los 220 MB
>>>

Ahora, probemos un ejemplo que involucre generadores. Reinicia Python y prueba esto:

>>> # REINICIAR
>>> import tracemalloc
>>> tracemalloc.start()
>>> import csv
>>> f = open('Data/ctabus.csv')
>>> f_csv = csv.reader(f)
>>> headers = next(f_csv)
>>> rows = (dict(zip(headers,row)) for row in f_csv)
>>> rt22 = (row for row in rows if row['route'] == '22')
>>> max(rt22, key=lambda row: int(row['rides']))
{'date': '06/11/2008', 'route': '22', 'daytype': 'W', 'rides': 26896}
>>> tracemalloc.get_traced_memory()
... observe el resultado. Debería ser MUCHO más pequeño que antes
>>>

Tenga en cuenta que acaba de procesar todo el conjunto de datos como si estuviera almacenado como una secuencia de diccionarios. Sin embargo, en ningún lugar creó ni almacenó una lista de diccionarios. No todos los problemas se pueden estructurar de esta manera, pero si puede trabajar con datos de manera iterativa, las expresiones generadoras pueden ahorrar una gran cantidad de memoria.
