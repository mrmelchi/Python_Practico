Ejercicio 1.4

Objetivos:

  • Repasar cómo definir funciones simples
  • Manejo de excepciones

Archivos creados: Ninguno

Archivos modificados: pcost.py

(a) Definición de una función

Tome el programa pcost.py que escribió en el último ejercicio y conviértalo en una función portfolio_cost(filename) que toma un nombre de archivo como entrada, lee los datos de la cartera en ese archivo y devuelve el costo total de la cartera como un número de punto flotante. Una vez que haya escrito la función, haga que su programa la llame simplemente agregando esta declaración al final:

print(portfolio_cost('Data/portfolio.dat'))

Ejecute su programa y asegúrese de que produzca el mismo resultado que antes.

(b) Agregar manejo de errores

Al escribir programas que procesan datos, es común encontrar errores relacionados con datos incorrectos (malformados, campos faltantes, etc.). Modifique su programa pcost.py para leer el archivo de datos Data/portfolio3.dat y ejecutarlo (pista: debería bloquearse).

Modifique su función levemente para que pueda recuperarse de líneas con datos incorrectos. Por ejemplo, las funciones de conversión int() y float() lanzan una excepción ValueError si no pueden convertir la entrada. Use try y except para capturar e imprimir un mensaje de advertencia sobre las líneas que no se pueden analizar. Por ejemplo:

No se pudo analizar: 'C - 53.08\n'
Motivo: literal inválido para int() con base 10: '-'
No se pudo analizar: 'DIS - 34.20\n'
Motivo: literal inválido para int() con base 10: '-'
...

Intente ejecutar su programa en el archivo Data/portfolio3.dat nuevamente. Debería ejecutarse correctamente a pesar de los mensajes de advertencia impresos.

(c) Experimentación interactiva

Ejecute su programa pcost.py y llame a la función portfolio_cost() directamente desde el intérprete interactivo.

>>> portfolio_cost('Data/portfolio.dat')
44671.15
>>> portfolio_cost('Data/portfolio2.dat')
19908.75
>>>

Nota: Para hacer esto, es posible que tengas que ejecutar Python usando la opción -i. Por ejemplo:

bash % python3 -i pcost.py

Vamos a escribir muchos programas en los que definirás funciones y experimentarás de forma interactiva. Asegúrate de saber cómo hacer esto.
