Ejercicio 7.5

Objetivos:

  • Crear tu primera metaclase

Archivos creados: mymeta.py

(a) Crear tu primera metaclase

Crea un archivo llamado mymeta.py e introduce el siguiente código (de las diapositivas):

# mymeta.py

class mytype(type):
    @staticmethod
    def __new__(meta, name, bases, __dict__):
        print("Creating class :", name)
        print("Base classes   :", bases)
        print("Attributes     :", list(__dict__))
        return super().__new__(meta, name, bases, __dict__)

class myobject(metaclass=mytype):
    pass

Una vez hecho esto, define una clase que Hereda de myobject en lugar de object. Por ejemplo:

class Stock(myobject):
    def __init__(self, name, shares, price):
        self.name = name
        self.shares = shares
        self.price = price
    def cost(self):
        return self.shares * self.price
    def sell(self, nshares):
        self.shares -= nshares

Intenta ejecutar tu código y crear instancias de Stock. Observa qué sucede. Deberías ver las sentencias de impresión de tu mytype ejecutándose una vez cuando se define la clase Stock. ¿Qué sucede si heredas de Stock?

class MyStock(Stock):
    pass

Deberías seguir viendo tu metaclase en funcionamiento. Las metaclases son persistentes, ya que se aplican a lo largo de toda la jerarquía de herencia.

Discusión

¿Por qué querrías hacer algo así? La principal ventaja de una metaclase es que permite al programador capturar detalles sobre las clases justo antes de su creación. Por ejemplo, en el método __new__(), se proporcionan todos los detalles básicos, incluyendo el nombre de la clase, las clases base y los datos de los métodos. Si se inspeccionan estos datos, se pueden realizar diversos tipos de comprobaciones de diagnóstico. Si se es más audaz, se pueden modificar los datos y cambiar lo que se incluye en la definición de la clase al crearla. Huelga decir que existen muchas posibilidades de que se produzcan terribles maldades diabólicas.
