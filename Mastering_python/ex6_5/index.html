Ejercicio 6.5

Objetivos:

  • Aprender a definir un objeto invocable adecuado

Archivos modificados: validate.py

En el Ejercicio 4.3, creaste una serie de clases Validator para realizar diferentes tipos de comprobaciones de tipo y valor. Por ejemplo:

>>> from validate import Integer
>>> Integer.check(1)
>>> Integer.check('hello')
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
  File "validate.py", line 21, in check
    raise TypeError(f'Expected {cls.expected_type}')
TypeError: Expected <class 'int'>
>>>

Puedes usar los validadores en funciones como esta:

>>> def add(x, y):
        Integer.check(x)
        Integer.check(y)
        return x + y

>>>

En este ejercicio, vamos a ir un paso más allá. ## (a) Creación de un objeto invocable

En el archivo validate.py, comience creando una clase como esta:

# validate.py
...

class ValidatedFunction:
    def __init__(self, func):
        self.func = func

    def __call__(self, *args, **kwargs):
        print('LLamando', self.func)
        result = self.func(*args, **kwargs)
        return result

Pruebe la clase aplicándola a una función:

>>> def add(x, y):
        return x + y

>>> add = ValidatedFunction(add)
>>> add(2, 3)
LLamando <function add at 0x1014df598>
5
>>>

(b) Aplicación

Modifique la La clase ValidatedFunction para que aplique las comprobaciones de valores adjuntas mediante anotaciones de función. Por ejemplo:

>>> def add(x: Integer, y:Integer):
        return x + y
>>> add = ValidatedFunction(add)
>>> add(2,3)
5
>>> add('two','three')
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
  File "validate.py", line 67, in __call__
    self.func.__annotations__[name].check(val)
  File "validate.py", line 21, in check
    raise TypeError(f'Expected {cls.expected_type}')
TypeError: expected <class 'int'>
>>>>

Sugerencia: Para ello, experimente con la vinculación de firmas. Usa el método bind() de los objetos Signature para enlazar los argumentos de función con sus nombres. Luego, cruza esta información con el atributo __annotations__ para obtener las diferentes clases de validación. Recuerda que estás creando un objeto que parece una función, pero en realidad no lo es. Hay algo mágico detrás de escena.

(c) Usar como método (Desafío)

Un objeto invocable personalizado suele presentar problemas si se usa como método personalizado. Por ejemplo, prueba esto:

class Stock:
    def __init__(self, name, shares, price):
        self.name = name
        self.shares = shares
        self.price = price

    @property
    def cost(self):
        return self.shares * self.price

    def sell(self, nshares:Integer):
        self.shares -= nshares
    sell = ValidatedFunction(sell)     # Falla

Verás que la función sell() encapsulada falla estrepitosamente:

>>> s = Stock('GOOG', 100, 490.1)
>>> s.sell(10)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
  File "validate.py", line 64, in __call__
    bound = self.signature.bind(*args, **kwargs)
  File "/usr/local/lib/python3.6/inspect.py", line 2933, in bind
    return args[0]._bind(args[1:], kwargs)
  File "/usr/local/lib/python3.6/inspect.py", line 2848, in _bind
    raise TypeError(msg) from None
TypeError: missing a required argument: 'nshares'
>>>

Extra: Averigua por qué falla, pero no pierdas mucho tiempo probándolo.
