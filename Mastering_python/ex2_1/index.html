Ejercicio 2.1

Objetivos:

  • Descubrir la forma más eficiente en términos de memoria para almacenar una gran cantidad de datos.
  • Aprender sobre las diferentes formas de representar registros, incluidas tuplas, diccionarios, clases y tuplas con nombre.

En este ejercicio, analizamos diferentes opciones para representar estructuras de datos teniendo en cuenta el uso y la eficiencia de la memoria. Muchas personas usan Python para realizar varios tipos de análisis de datos, por lo que conocer las diferentes opciones y sus ventajas y desventajas es una información útil.

(a) Atascado en el autobús

El archivo Data/ctabus.csv es un archivo CSV que contiene datos diarios de pasajeros del sistema de autobuses de la Autoridad de Tránsito de Chicago (CTA) desde el 1 de enero de 2001 hasta el 31 de agosto de 2013. Contiene aproximadamente 577000 filas de datos. Utilice Python para ver algunas líneas de datos y ver cómo se ve:

>>> f = open('Data/ctabus.csv')
>>> next(f)
'route,date,daytype,rides\n'
>>> next(f)
'3,01/01/2001,U,7354\n'
>>> next(f)
'4,01/01/2001,U,9288\n'
>>>

Hay 4 columnas de datos.

  • route: Columna 0. El nombre de la ruta del autobús.
  • date: Columna 1. Una cadena de fecha con el formato MM/DD/AAAA.
  • daytype: Columna 2. Un código de tipo de día (U=domingo/feriado, A=sábado, W=día laborable)
  • rides: Columna 3. Número total de pasajeros (entero)

La columna rides registra el número total de personas que subieron a un autobús en esa ruta en un día determinado. Por lo tanto, según el ejemplo, 7354 personas subieron al autobús número 3 el 1 de enero de 2001.

(b) Uso básico de la memoria del texto

Obtengamos una línea base de la memoria necesaria para trabajar con este archivo de datos. Primero, reinicia Python e intenta un experimento muy simple: simplemente toma el archivo y almacena sus datos en una sola cadena:

>>>> # --- RESTART 
>>> import tracemalloc
>>> f = open('Data/ctabus.csv')
>>> tracemalloc.start()
>>> data = f.read()
>>> len(data)
12361039
>>> current, peak = tracemalloc.get_traced_memory()
>>> current
12369664
>>> peak
24730766
>>>

Los resultados pueden variar un poco, pero deberías ver el uso actual de la memoria en el rango de 12 MB con un pico de 24 MB.

¿Qué sucede si lees el archivo completo en una lista de cadenas? Reinicie Python y pruebe esto:

>>> # --- RESTART
>>> import tracemalloc
>>> f = open('Data/ctabus.csv')
>>> tracemalloc.start()
>>> lines = f.readlines()
>>> len(lines)
577564
>>> current, peak = tracemalloc.get_traced_memory()
>>> current
45828030
>>> peak
45867371
>>>

Debería ver que el uso de memoria aumenta significativamente hasta el rango de 40-50 MB. Punto para reflexionar: ¿cuál podría ser la fuente de esa sobrecarga adicional?

(c) Una lista de tuplas

En la práctica, puede leer los datos en una lista y convertir cada línea en alguna otra estructura de datos. Aquí hay un programa readrides.py que lee el archivo completo en una lista de tuplas usando el módulo csv:

# readrides.py

import csv

def read_rides_as_tuples(filename):
    '''
    Lee los datos del recorrido en autobús como una lista de tuplas
    '''
    records = []
    with open(filename) as f:
        rows = csv.reader(f)
        headings = next(rows)     # Salta encabezados
        for row in rows:
            route = row[0]
            date = row[1]
            daytype = row[2]
            rides = int(row[3])
            record = (route, date, daytype, rides)
            records.append(record)
    return records

if __name__ == '__main__':
    import tracemalloc
    tracemalloc.start()
    rows = read_rides_as_tuples('Data/ctabus.csv')
    print('Memory Use: Current %d, Peak %d' % tracemalloc.get_traced_memory())

Ejecute este programa usando python3 -i readrides.py y observe el contenido resultante de rows. Debería obtener una lista de tuplas como esta:

>>> len(rows)
577563
>>> rows[0]
('3', '01/01/2001', 'U', 7354)
>>> rows[1]
('4', '01/01/2001', 'U', 9288)

Observe el uso de memoria resultante. Debería ser sustancialmente mayor que en la parte (b).

(d) Uso de la memoria de otras estructuras de datos

Python ofrece muchas opciones diferentes para representar estructuras de datos. Por ejemplo:

# Una tupla
row = (route, date, daytype, rides)

# Un diccionario
row = {
    'route': route,
    'date': date,
    'daytype': daytype,
    'rides': rides,
}

# Una clase
class Row:
    def __init__(self, route, date, daytype, rides):
        self.route = route
        self.date = date
        self.daytype = daytype
        self.rides = rides

# Una tupla con nombre
from collections import namedtuple
Row = namedtuple('Row', ['route', 'date', 'daytype', 'rides'])

# Una clase con __slots__
class Row:
    __slots__ = ['route', 'date', 'daytype', 'rides']
    def __init__(self, route, date, daytype, rides):
        self.route = route
        self.date = date
        self.daytype = daytype
        self.rides = rides

Su tarea es la siguiente: crear diferentes versiones de la función read_rides() que utilicen cada una de estas estructuras de datos para representar una sola fila de datos. Descubra qué enfoque ofrece el almacenamiento más eficiente si estuviera trabajando con una gran cantidad de datos a la vez.
