Ejercicio 3.4

Objetivos:

  • Aprender a encapsular elementos internos de objetos mediante atributos privados, propiedades y ranuras

Archivos modificados: stock.py

(a) Atributos privados

Como regla general, los atributos que son internos a una clase deben tener un guión bajo inicial. En el ejercicio anterior, la clase Stock tenía una variable de clase types que se usaba para convertir filas de datos. Cambie el código para que esta variable tenga un guión bajo inicial.

(b) Propiedades para atributos calculados

Anteriormente, definió una clase Stock. Por ejemplo:

>>> s = Stock('GOOG',100,490.10)
>>> s.name
'GOOG'
>>> s.shares
100
>>> s.price
490.1
>>> s.cost()
49010.0
>>>

Usando una propiedad, convierta cost() en un atributo que ya no requiere los paréntesis. Por ejemplo:

>>> s = Stock('GOOG', 100, 490.1)
>>> s.cost      # Propiedad. Calcula el costo
49010.0
>>>

(c) Aplicación de reglas de validación

Mediante el uso de propiedades y atributos privados, modifique el atributo shares de la clase Stock para que solo se le pueda asignar un valor entero no negativo. Además, modifique el atributo price para que solo se le pueda asignar un valor de punto flotante no negativo.

El nuevo objeto debería funcionar casi exactamente igual que el anterior, excepto por la verificación adicional de tipo y valor.

>>> s = Stock('GOOG', 100, 490.10)
>>> s.shares = 50          # OK
>>> s.shares = '50'
Traceback (most recent call last):
...
TypeError: Expected integer
>>> s.shares = -10
Traceback (most recent call last):
...
ValueError: shares must be >= 0

>>> s.price = 123.45       # OK
>>> s.price = '123.45'
Traceback (most recent call last):
...
TypeError: Expected float
>>> s.price = -10.0
Traceback (most recent call last):
...
ValueError: price must be >= 0
>>>

(d) Adición __slots__

Modifique su nueva clase Stock para utilizar __slots__. Descubrirá que debe utilizar un conjunto de nombres de atributos diferente al anterior; específicamente, deberá incluir los nombres de atributos privados (por ejemplo, si una propiedad almacena un valor en un atributo _shares, ese es el nombre que incluye en __slots__). Verifique que la clase aún funcione y que ya no pueda agregar nuevos atributos.

>>> s = Stock('GOOG', 100, 490.10)
>>> s.spam = 42
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
AttributeError: 'Stock' object has no attribute 'spam'
>>>

(e) Reconciliación de tipos

En la clase Stock actual, hay una variable de clase _types que proporciona conversiones al leer desde un archivo, pero también hay propiedades que imponen tipos. ¿Quién está a cargo de este programa? Corrija las definiciones de propiedades para que utilicen los tipos especificados en la variable de clase _types. Asegúrese de que las propiedades funcionen cuando se cambien los tipos mediante subclasificación. Por ejemplo:

>>> from decimal import Decimal
>>> class DStock(Stock):
        _types = (str, int, Decimal)

>>> s = DStock('AA', 50, Decimal('91.1'))
>>> s.price = 92.3
Traceback (most recent call last):
...
TypeError: Expected a Decimal
>>>

Discusión

La clase Stock resultante al final de este ejercicio es un lío confuso de propiedades, verificación de tipos, constructores y otros detalles. Imagine lo desagradable que sería mantener un código que incluyera docenas o cientos de definiciones de clases de este tipo.

Vamos a descubrir cómo simplificar las cosas considerablemente, pero llevará algo de tiempo y algunas técnicas más avanzadas. Estén atentos.
