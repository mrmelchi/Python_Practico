Ejercicio 5.4

Objetivos:

  • Aprender más sobre los cierres

En esta sección, analizamos brevemente algunos de los aspectos más inusuales de los cierres.

(a) Cierres como estructura de datos

Un posible uso de los cierres es como herramienta para la encapsulación de datos. Pruebe este ejemplo:

def counter(value):
    def incr():
        nonlocal value
        value += 1
        return value

    def decr():
        nonlocal value
        value -= 1
        return value

    return incr, decr

Este código define dos funciones internas que manipulan un valor. Pruébalo:

>>> up, down = counter(0)
>>> up()
1
>>> up()
2
>>> up()
3
>>> down()
2
>>> down()
1
>>>

Observa que aquí no hay ninguna definición de clase. Además, tampoco hay ninguna variable global. Sin embargo, las funciones up() y down() manipulan algún valor oculto. Es bastante mágico.

(b) Clousures como generador de código

En el Ejercicio 4.3, desarrollaste una colección de clases descriptoras que permitían la verificación de tipos de los atributos de los objetos. Por ejemplo:


class Stock:
    name = String()
    shares = Integer()
    price = Float()

Este tipo de cosas también se pueden implementar mediante cierres. Define un archivo typedproperty.py y escribe el siguiente código:

# typedproperty.py

def typedproperty(name, expected_type):
    private_name = '_' + name

    @property
    def value(self):
        return getattr(self, private_name)

    @value.setter
    def value(self, val):
        if not isinstance(val, expected_type):
            raise TypeError(f'Expected {expected_type}')
        setattr(self, private_name, val)

    return value

Esto parece bastante extraño, pero la función genera código. Se usaría en una definición de clase como esta:

from typedproperty import typedproperty

class Stock:
    name = typedproperty('name', str)
    shares = typedproperty('shares', int)
    price = typedproperty('price', float)

    def __init__(self, name, shares, price):
        self.name = name
        self.shares = shares
        self.price = price

Verifique que esta clase realice la verificación de tipos de la misma manera que el código del descriptor.

Añade las funciones String(), Integer() y Float() al archivo typedproperty.py para que puedas escribir el siguiente código:

from typedproperty import String, Integer, Float

class Stock:
    name = String('name')
    shares = Integer('shares')
    price = Float('price')
    def __init__(self, name, shares, price):
        self.name = name
        self.shares = shares
        self.price = price

(c) Desafío: Eliminación de nombres

Modifica el código de typedproperty.py para que los nombres de los atributos ya no sean necesarios:

from typedproperty import String, Integer, Float

class Stock:
    name = String()
    shares = Integer()
    price = Float()
    def __init__(self, name, shares, price):
        self.name = name
        self.shares = shares
        self.price = price

Sugerencia: Para ello, recuerde el método __set_name__() de los objetos descriptores, que se invoca al incluir descriptores en la definición de una clase.
