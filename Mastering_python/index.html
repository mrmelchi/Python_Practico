Copyright (C) 2007-2023 David M. Beazley https://www.dabeaz.com

Esta página contiene enlaces a todos los ejercicios del curso. Para obtener la mejor experiencia, los ejercicios deben realizarse en orden, ya que los ejercicios posteriores suelen basarse en ejercicios anteriores. El directorio Solutions/ contiene soluciones completamente elaboradas para cada ejercicio. Puede usarlo si se queda atascado o necesita restablecer su código a un estado funcional.

Antes de comenzar, debe bifurcar/clonar el repositorio de GitHub para tener una copia local en su máquina. Los ejercicios suponen que todo su trabajo se llevará a cabo en el directorio de nivel superior python-mastery.

Las diapositivas de presentación del curso asociado se pueden encontrar en PythonMastery.pdf.
