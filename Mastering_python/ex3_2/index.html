Ejercicio 3.2

Objetivos:

  • Aprender sobre el acceso a atributos
  • Aprender a usar getattr(), setattr() y funciones relacionadas.
  • Experimentar con métodos enlazados.

Archivos creados: tableformat.py

(a) Las tres operaciones

El sistema de objetos de Python completo consta de solo tres operaciones básicas: obtener, configurar y eliminar atributos. Normalmente, se accede a ellos a través del punto (.) de la siguiente manera:

>>> s = Stock('GOOG', 100, 490.1)
>>> s.name              # obtener
'GOOG'
>>> s.shares = 50       # configurar
>>> del s.shares        # eliminar
>>>

Las tres operaciones también están disponibles como funciones. Por ejemplo:

>>> getattr(s, 'name')        # Igual que s.name
'GOOG'
>>> setattr(s, 'shares', 50)  # Igual que s.shares = 50
>>> delattr(s, 'shares')      # Igual que del s.shares
>>>

Se puede utilizar una función adicional hasattr() para sondear un objeto en busca de la existencia de un atributo:

>>> hasattr(s, 'name')
True
>>> hasattr(s, 'blah')
False
>>>

(b) Uso de getattr()

La función getattr() es extremadamente útil para escribir código que procesa objetos de una manera extremadamente genérica. Para ilustrarlo, considere este ejemplo que imprime un conjunto de atributos definidos por el usuario:

>>> s= Stock('GOOG', 100, 490.1)
>>> fields = ['name','shares','price']
>>> for name in fields:
print(name, getattr(s, name))

name GOOG
shares 100
price 490.1
>>>

(c) Salida de tabla

En el Ejercicio 3.1, escribió una función print_portfolio() que generó una tabla con un formato agradable. Esa función se adaptó a una lista de objetos Stock. Sin embargo, se puede generalizar por completo para que funcione con cualquier lista de objetos utilizando la técnica de la parte (b).

Cree un nuevo módulo llamado tableformat.py. En ese programa, escriba una función print_table() que tome una secuencia (lista) de objetos, una lista de nombres de atributos e imprima una tabla bien formateada. Por ejemplo:

>>> import stock
>>> import tableformat
>>> portfolio = stock.read_portfolio('Data/portfolio.csv')
>>> tableformat.print_table(portfolio, ['name','shares','price'])
      name     shares      price
---------- ---------- ---------- 
        AA        100       32.2
       IBM         50       91.1
       CAT        150      83.44
      MSFT        200      51.23
        GE         95      40.37
      MSFT         50       65.1
       IBM        100      70.44

>>> tableformat.print_table(portfolio,['shares','name'])
    shares       name
---------- ---------- 
       100         AA
        50        IBM
       150        CAT
       200       MSFT
        95         GE
        50       MSFT
       100        IBM
>>>

Para simplificar, simplemente haga que la función print_table() imprima cada campo en una columna de 10 caracteres de ancho.

(d) Métodos enlazados

Puede resultar sorprendente, pero las llamadas a métodos se superponen a la maquinaria utilizada para atributos simples. Básicamente, un método es un atributo que se ejecuta cuando se agregan los paréntesis necesarios () para llamarlo como una función. Por ejemplo:

>>> s = Stock('GOOG',100,490.10)
>>> s.cost           # Looks up the method
<bound method Stock.cost of <__main__.Stock object at 0x409530>>
>>> s.cost()         # Looks up and calls the method
49010.0

>>> # Misma operación usando getattr()
>>> getattr(s, 'cost')
<bound method Stock.cost of <__main__.Stock object at 0x409530>>
>>> getattr(s, 'cost')()
49010.0
>>>

Un método enlazado se adjunta al objeto del que proviene. Si se modifica ese objeto, el método verá las modificaciones. Puede ver el objeto original inspeccionando el atributo __self__ del método.

>>> c = s.cost
>>> c()
49010.0
>>> s.shares = 75
>>> c()
36757.5
>>> c.__self__
<__main__.Stock object at 0x409530>
>>> c.__func__
<function cost at 0x37cc30>
>>> c.__func__(c.__self__)# Esto es lo que sucede detrás de escena al llamar a c()
36757.5
>>>

Pruébelo con el método sell() solo para asegurarse de que comprende la mecánica:

>>> f = s.sell
>>> f.__func__(f.__self__, 25) # Igual que s.sell(25)
>>> s.shares
50
>>>
