Ejercicio 9.1

Objetivos:

  • Repaso de los fundamentos de los módulos

Este ejercicio trata sobre algunos de los detalles más complejos de los módulos de biblioteca. Comienza este ejercicio creando un módulo de biblioteca muy simple:

# simplemod.py

x = 42 # Una variable global

# Una función simple
def foo():   
    print('x is', x)


# Una clase simple
class Spam:
    def yow(self):
        print('Yow!')

# Una sentencia de script
print('simplemod cargado')

(a) Carga del módulo y ruta del sistema

Intenta importar el módulo que acabas de crear:

>>> import simplemod
simplemod cargado
>>> simplemod.foo()
x is 42
>>>

Si esto falla con un ImportError, la configuración de la ruta es incorrecta. Revisa el valor de sys.path y corrígelo.

>>> import sys
>>> sys.path
... observa el resultado...
>>>

(b) Carga repetida de módulos

Asegúrate de comprender que los módulos solo se cargan una vez. Prueba una importación repetida y observa que no ves el resultado de la función print:

>>> import simplemod
>>>

Prueba a cambiar el valor de x y observa que una importación repetida no tiene efecto.

>>> simplemod.x
42
>>> simplemod.x = 13
>>> simplemod.x
13
>>> import simplemod
>>> simplemod.x
13
>>>

Usa importlib.reload() si quieres forzar la recarga de un módulo.

>>> import importlib
>>> importlib.reload(simplemod)
simplemod cargado
<module 'simplemod' from 'simplemod.py'>
>>> simplemod.x
42
>>>

sys.modules es un diccionario de todos los módulos cargados. Revísalo, elimina el módulo e intenta importarlo de nuevo.

>>> sys.modules
... mira la salida...
>>> sys.modules['simplemod']
<module 'simplemod' from 'simplemod.py'>
>>> del sys.modules['simplemod']
>>> import simplemod
simplemod cargado
>>>

(c) from module import

Reinicia Python e importa el símbolo seleccionado de un módulo.

>>> ############### [ REINICIAR ] ###############
>>> from simplemod import foo
simplemod cargado
>>> foo()
x es 42
>>>

Observa cómo se cargó todo el módulo (observa la salida de la función de impresión y cómo se usa la variable x).

Al usar from, el objeto del módulo no es visible. Por ejemplo:

>>> simplemod.foo()
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
NameError: name 'simplemod' is not defined
>>>

Asegúrate de comprender que, al exportar elementos desde un módulo, estos son simplemente referencias de nombre. Por ejemplo, prueba esto y explícalo:

>>> from simplemod import x,foo
>>> x
42
>>> foo()
x es 42
>>> x = 13
>>> foo()
x es 42 # !! Por favor, explícalo
>>> x
13
>>>

(d) Reload() roto

Crea una instancia:

>>> import simplemod
>>> s = simplemod.Spam()
>>> s.yow()
Yow!
>>>

Ahora, ve al archivo simplemod.py y cambia la implementación de Spam.yow() a la siguiente:

# simplemod.py
...

class Spam:
    def yow(self):
        print('More Yow!')

Ahora, observa lo que sucede al recargar. No reinicie Python para esta parte.

>>> importlib.reload(simplemod)
simplemod cargado
<module 'simplemod' from 'simplemod.py'>
>>> s.yow()
'Yow!'
>>> t = simplemod.Spam()
>>> t.yow()
'More Yow!'
>>>

Observa que tienes dos instancias de Spam, pero usan diferentes implementaciones del método yow(). Sí, de hecho, ambas versiones del código se cargan al mismo tiempo. También encontrarás otras rarezas. Por ejemplo:

>>> s
<simplemod.Spam object at 0x1006940b8>
>>> isinstance(s, simplemod.Spam)
False
>>> isinstance(t, simplemod.Spam)
True
>>>

En resumen: Probablemente sea mejor no depender de la recarga para nada importante. Podría funcionar bien si solo intentas depurar algunas cosas (siempre que seas consciente de sus limitaciones y peligros).
