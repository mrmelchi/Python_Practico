Ejercicio 9.4

Objetivos:

  • Explorar importaciones circulares
  • Importaciones dinámicas de módulos

En el último ejercicio, dividió el archivo tableformat.py en submódulos.

La última parte del archivo tableformat/formatter.py resultante se ha convertido en un caos de importaciones.

# tableformat.py
...

class TableFormatter(ABC):
    @abstractmethod
    def headings(self, headers):
        pass

    @abstractmethod
    def row(self, rowdata):
        pass

from .formats.text import TextTableFormatter
from .formats.csv import CSVTableFormatter
from .formats.html import HTMLTableFormatter

...

def create_formatter(name, column_formats=None, upper_headers=False):
    if name == 'text':
        formatter_cls = TextTableFormatter
    elif name == 'csv':
        formatter_cls = CSVTableFormatter
    elif name == 'html':
        formatter_cls = HTMLTableFormatter
    else:
        raise RuntimeError('Unknown format %s' % name)

    if column_formats:
        class formatter_cls(ColumnFormatMixin, formatter_cls):
            formats = column_formats

    if upper_headers:
        class formatter_cls(UpperHeadersMixin, formatter_cls):
            pass

    return formatter_cls()

Las importaciones en el medio del archivo son necesarias porque la función create_formatter() las necesita para encontrar las clases adecuadas. En realidad, todo es un desastre.

(a) Importaciones circulares

Intenta mover las siguientes sentencias de importación al principio del archivo formatter.py:

# formatter.py

from .formats.text import TextTableFormatter
from .formats.csv import CSVTableFormatter
from .formats.html import HTMLTableFormatter

class TableFormatter(ABC):
    @abstractmethod
    def headings(self, headers):
        pass

    @abstractmethod
    def row(self, rowdata):
        pass

...

Observa que ya no funciona. Intenta ejecutar el programa stock.py y observa el error sobre que TableFormatter no está definido. El orden de las sentencias de importación es importante y no puedes mover las importaciones a donde quieras.

Mueve las sentencias de importación a su lugar original. ¡Uf!

(b) Registro de subclases

Pruebe el siguiente experimento y observe:

>>> from structly.tableformat.formats.text import TextTableFormatter
>>> TextTableFormatter.__module__
'structly.tableformat.formats.text'
>>> TextTableFormatter.__module__.split('.')[-1]
'text'
>>>

Modifique la clase base TableFormatter añadiendo un diccionario y un método __init_subclass__():

class TableFormatter(ABC):
    _formats = { }

    @classmethod
    def __init_subclass__(cls):
        name = cls.__module__.split('.')[-1]
        TableFormatter._formats[name] = cls

    @abstractmethod
    def headings(self, headers):
        pass

    @abstractmethod
    def row(self, rowdata):
        pass

Esto hace que la clase padre rastree todas sus subclases. Échale un vistazo:

>>> from structly.tableformat.formatter import TableFormatter
>>> TableFormatter._formats
{'text': <class 'structly.tableformat.formats.text.TextTableFormatter'>, 
 'csv': <class 'structly.tableformat.formats.csv.CSVTableFormatter'>, 
 'html': <class 'structly.tableformat.formats.html.HTMLTableFormatter'>}
>>>

Modifica la función create_formatter() para buscar la clase en este diccionario:

def create_formatter(name, column_formats=None, upper_headers=False):
    formatter_cls = TableFormatter._formats.get(name)
    if not formatter_cls:
        raise RuntimeError('Formato desconocido %s' % name)

    if column_formats:
        class formatter_cls(ColumnFormatMixin, formatter_cls):
            formats = column_formats

    if upper_headers:
        class formatter_cls(UpperHeadersMixin, formatter_cls):
            pass

    return formatter_cls()

Ejecute el programa stock.py. Asegúrese de que siga funcionando después de realizar estos cambios. Cabe destacar que todas las declaraciones de importación siguen ahí. Básicamente, ha limpiado un poco el código y eliminado los nombres de clase predefinidos.

(c) Importaciones dinámicas

Ya está listo para la frontera final. Elimine las siguientes declaraciones de importación por completo:

# formatter.py
...

from .formats.text import TextTableFormatter # DELETE
from .formats.csv import CSVTableFormatter # DELETE
from .formats.html import HTMLTableFormatter # DELETE
...

Ejecute el código stock.py de nuevo; debería fallar con un error. No tiene información sobre el formateador de texto. Corríjalo añadiendo este pequeño fragmento de código a create_formatter():

def create_formatter(name, column_formats=None, upper_headers=False):
    if name not in TableFormatter._formats:
        __import__(f'{__package__}.formats.{name}')
    ...

Este código intenta una importación dinámica de un módulo formateador si no se conoce nada sobre el nombre. La importación sola (si funciona) registrará la clase con el diccionario _formats y todo funcionará. ¡Magia! Intenta ejecutar el código stock.py y asegúrate de que funcione después.
