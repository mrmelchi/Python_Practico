Objetivos:

  • Usar generadores para configurar pipelines de procesamiento

Archivos creados: ticker.py

Nota

Para este ejercicio, el programa stocksim.py debe seguir ejecutándose en segundo plano. Usarás la función follow() que escribiste en el ejercicio anterior.

(a) Configurando procesamiento de tubería

Una gran ventaja de los generadores es que permiten crear programas que configuran pipelines de procesamiento, de forma similar a las tuberías en sistemas Unix. Experimente con este concepto siguiendo estos pasos:

>>> from follow import follow
>>> import csv
>>> lines = follow('Data/stocklog.csv')
>>> rows = csv.reader(lines)
>>> for row in rows:
        print(row)

['BA', '98.35', '6/11/2007', '09:41.07', '0.16', '98.25', '98.35', '98.31', '158148']
['AA', '39.63', '6/11/2007', '09:41.07', '-0.03', '39.67', '39.63', '39.31', '270224']
['XOM', '82.45', '6/11/2007', '09:41.07', '-0.23', '82.68', '82.64', '82.41', '748062']
['PG', '62.95', '6/11/2007', '09:41.08', '-0.12', '62.80', '62.97', '62.61', '454327']
...

Bueno, eso es interesante. Lo que ven aquí es que la salida de la función follow() se ha canalizado a la función csv.reader() y ahora obtenemos una secuencia de filas divididas.

(b) Creación de más componentes de la tubería

En el archivo ticker.py, define la siguiente clase (usando el código de estructura anterior) y configura una tubería:

# ticker.py

from structure import Structure

class Ticker(Structure):
    name = String()
    price = Float()
    date = String()
    time = String()
    change = Float()
    open = Float()
    high = Float()
    low = Float()
    volume = Integer()

if __name__ == '__main__':
    from follow import follow
    import csv
    lines = follow('Data/stocklog.csv')
    rows = csv.reader(lines)
    records = (Ticker.from_row(row) for row in rows)
    for record in records:
        print(record)

Al ejecutar esto, deberías ver un resultado como este:

(c) Continúa

¡Ah, puedes hacerlo mejor! Incorporémoslo a tu código de generación de tablas. Cambia el programa a lo siguiente:

# ticker.py
...

if __name__ == '__main__':
    from follow import follow
    import csv
    from tableformat import create_formatter, print_table

    formatter = create_formatter('text')

    lines = follow('Data/stocklog.csv')
    rows = csv.reader(lines)
    records = (Ticker.from_row(row) for row in rows)
    negative = (rec for rec in records if rec.change < 0)
    print_table(negative, ['name','price','change'], formatter)

Discusión

Algunas lecciones aprendidas: Se pueden crear varias funciones generadoras y encadenarlas para realizar procesamientos que involucren tuberías de flujo de datos.

Un buen modelo mental para las funciones generadoras podrían ser los bloques de Lego. Se puede crear una colección de pequeños patrones iteradores y empezar a apilarlos de diversas maneras. Puede ser una forma extremadamente potente de programar.
