Ejercicio 5.5

Objetivos:

  • Aprender más sobre el manejo y registro de excepciones

Archivos modificados: reader.py

(a) Captura de excepciones

En lugar de bloquearse con datos incorrectos, modifique el código para que emita un mensaje de advertencia. El resultado final debería ser una lista de las filas convertidas correctamente. Por ejemplo:

>>> port = read_csv_as_dicts('Data/missing.csv', types=[str, int, float])
Row 4: Bad row: ['C', '', '53.08']
Row 7: Bad row: ['DIS', '50', 'N/A']
Row 8: Bad row: ['GE', '', '37.23']
Row 13: Bad row: ['INTC', '', '21.84']
Row 17: Bad row: ['MCD', '', '51.11']
Row 19: Bad row: ['MO', '', '70.09']
Row 22: Bad row: ['PFE', '', '26.40']
Row 26: Bad row: ['VZ', '', '42.92']
>>> len(port)
20
>>>

Nota: Realizar este cambio puede ser un poco complicado debido al uso previo de la función integrada map(). Es posible que deba abandonar este enfoque, ya que no existe una forma sencilla de capturar y gestionar excepciones en map().

(b) Logging

Modifique el código para que los mensajes de advertencia se emitan mediante el módulo logging. Además, proporcione información de depuración opcional que indique el motivo del fallo. Por ejemplo:

>>> import reader
>>> import logging
>>> logging.basicConfig(level=logging.DEBUG)
>>> port = reader.read_csv_as_dicts('Data/missing.csv', types=[str, int, float])
