Ejercicio 3.3

Objetivos:

  • Aprender sobre las variables y métodos de clase

Archivos modificados: stock.py, reader.py

Las instancias de la clase Stock definida en el ejercicio anterior normalmente se crean de la siguiente manera:

>>> s = Stock('GOOG', 100, 490.1)
>>>

Sin embargo, la función read_portfolio() también crea instancias a partir de filas de datos leídas de archivos. Por ejemplo, se utiliza un código como el siguiente:

>>> import csv
>>> f = open('Data/portfolio.csv')
>>> rows = csv.reader(f)
>>> headers = next(rows)
>>> row = next(rows)
>>> row
['AA', '100', '32.20']
>>> s = Stock(row[0], int(row[1]), float(row[2]))
>>>

(a) Constructores alternativos

Quizás la creación de un Stock a partir de una fila de datos sin procesar se gestione mejor con un constructor alternativo. Modifique la clase Stock para que tenga una variable de clase types y un método de clase from_row() de la siguiente manera:

class Stock:
    types = (str, int, float)
    def __init__(self, name, shares, price):
        self.name = name
        self.shares = shares
        self.price = price

    @classmethod
    def from_row(cls, row):
        values = [func(val) for func, val in zip(cls.types, row)]
        return cls(*values)
    ...

A continuación, se muestra cómo probarlo:

>>> row = ['AA', '100', '32.20']
>>> s = Stock.from_row(row)
>>> s.name
'AA'
>>> s.shares
100
>>> s.price
32.2
>>> s.cost()
3220.0000000000005
>>>

Observe atentamente cómo los valores de cadena en la fila se han convertido a un tipo adecuado.

(b) Variables de clase y herencia

Las variables de clase como types se utilizan a veces como un mecanismo de personalización cuando se utiliza la herencia. Por ejemplo, en la clase Stock, los tipos se pueden cambiar fácilmente en una subclase. Pruebe este ejemplo que cambia el atributo price a una instancia Decimal (que suele ser más adecuada para cálculos financieros):

>>> from decimal import Decimal
>>> class DStock(Stock):
        types = (str, int, Decimal)

>>> row = ['AA', '100', '32.20']
>>> s = DStock.from_row(row)
>>> s.price
Decimal('32.20')
>>> s.cost()
Decimal('3220.0')
>>>

Discusión sobre el diseño

El problema que se aborda en este ejercicio se refiere a la conversión de datos leídos desde un archivo. ¿Tendría sentido realizar estas conversiones en el método __init__() de la clase Stock? Por ejemplo:

class Stock:
    def __init__(self, name, shares, price):
        self.name = str(name)
        self.shares = int(shares)
        self.price = float(price)

Al hacer esto, convertirías una fila de datos de la siguiente manera:

>>> row = ['AA', '100', '32.20']
>>> s = Stock(*row)
>>> s.name
'AA'
>>> s.shares
100
>>> s.price
32.2
>>>

¿Esto es bueno o malo? ¿Qué piensas? En general, creo que es un diseño cuestionable ya que mezcla dos cosas diferentes: la creación de una instancia y la conversión de datos. Además, las conversiones implícitas en __init__() limitan la flexibilidad y pueden introducir errores extraños si un usuario no presta mucha atención.

(d) Generalización

Una característica útil de los métodos de clase es que puede usarlos para poner una interfaz de creación de instancias altamente uniforme en una amplia variedad de clases y escribir funciones de utilidad de propósito general que las utilicen.

Anteriormente, creó un archivo reader.py que tenía algunas funciones para leer datos CSV. Agregue la siguiente función read_csv_as_instances() al archivo que acepta una clase como entrada y usa el método de clase from_row() para crear una lista de instancias:

# reader.py
...

def read_csv_as_instances(filename, cls):
    '''
    Read a CSV file into a list of instances
    '''
    records = []
    with open(filename) as f:
        rows = csv.reader(f)
        headers = next(rows)
        for row in rows:
            records.append(cls.from_row(row))
    return records

Deshágase de la función read_portfolio(); ya no la necesita. Si desea leer una lista de objetos Stock, haga lo siguiente:

>>> # Leer una cartera de instancias de Stock
>>> from reader import read_csv_as_instances
>>> from stock import Stock
>>> portfolio = read_csv_as_instances('Data/portfolio.csv', Stock)
>>> portfolio
[<__main__.Stock object at 0x100674748>, 
<__main__.Stock object at 0x1006746d8>, 
<__main__.Stock object at 0x1006747b8>, 
<__main__.Stock object at 0x100674828>, 
<__main__.Stock object at 0x100674898>, 
<__main__.Stock object at 0x100674908>, 
<__main__.Stock object at 0x100674978>]
>>>

A continuación, se muestra otro ejemplo de cómo puede usar read_csv_as_instances() con una clase completamente diferente:

>>> class Row:
         def __init__(self, route, date, daytype, numrides):
             self.route = route
             self.date = date
             self.daytype = daytype
             self.numrides = numrides
         @classmethod
         def from_row(cls, row):
             return cls(row[0], row[1], row[2], int(row[3]))

>>> rides = read_csv_as_instances('Data/ctabus.csv', Row)
>>> len(rides)
577563
>>>

Discusión

Este ejercicio ilustra los dos usos más comunes de las Variables de clase y métodos de clase. Las variables de clase se utilizan a menudo para contener un parámetro global (por ejemplo, una configuración) que se comparte entre todas las instancias. A veces, las subclases heredan de la clase base y anulan la configuración para cambiar el comportamiento.

Los métodos de clase se utilizan con mayor frecuencia para implementar constructores alternativos, como se muestra. Una forma común de detectar dichos métodos de clase es buscar la palabra "from" en el nombre. Por ejemplo, aquí hay un ejemplo sobre diccionarios integrados:

>>> d = dict.fromkeys(['a','b','c'], 0) # método de clase
>>> d
{'a': 0, 'c': 0, 'b': 0}
>>>
