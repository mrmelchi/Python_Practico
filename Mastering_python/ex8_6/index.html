Ejercicio 8.6

Objetivos:

  • Aprender a delegar generadores

Archivos modificados: cofollow.py, server.py

Un problema potencial en el código que depende de generadores es la dificultad de ocultar detalles al usuario y escribir bibliotecas. Generalmente, se requieren muchos mecanismos de bajo nivel para controlar todo, y suele ser bastante complicado exponerlos directamente a los usuarios.

A partir de Python 3.3, se puede usar una nueva sentencia yield from para delegar generadores a otra función. Es una forma útil de limpiar el código que depende de generadores.

(a) Ejemplo: Recepción de mensajes

En el Ejercicio 8.3, analizamos las definiciones de corrutinas. Las corrutinas eran funciones a las que se enviaban datos. Por ejemplo:

>>> from cofollow import consumer
>>> @consumer
    def printer():
        while True:
            item = yield
            print('Got:', item)

>>> p = printer()
>>> p.send('Hola')
Got: Hola
>>> p.send('Mundo')
Got: Mundo
>>>

En aquel momento, podría haber sido interesante usar yield para recibir un valor. Sin embargo, si se analiza el código, parece bastante extraño: ¿un yield simple como ese? ¿Qué está pasando?

En el archivo cofollow.py, defina la siguiente función:

def receive(expected_type):
    msg = yield
    assert isinstance(msg, expected_type), 'Expected type %s' % (expected_type)
    return msg

Esta función recibe un mensaje, pero luego verifica que sea del tipo esperado. Pruébalo:

>>> from cofollow import consumer, receive
>>> @consumer
    def print_ints():
        while True:
             val = yield from receive(int)
             print('Got:', val)

>>> p = print_ints()
>>> p.send(42)
Got: 42
>>> p.send(13)
Got: 13
>>> p.send('13')
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
  ...
AssertionError: Expected type <class 'int'>
>>>

Desde el punto de vista de la legibilidad, la sentencia yield from receive(int) es un poco más descriptiva: indica que la función cederá hasta que reciba un mensaje de un tipo determinado.

Ahora, modifica todas las corrutinas en coticker.py para usar la nueva función receive() y asegúrate de que el código del Ejercicio 8.3 siga funcionando.

(b) Encapsulando un socket

En el ejercicio anterior, escribiste un servidor de eco de red simple usando generadores. El código del servidor se veía así:

def tcp_server(address, handler):
    sock = socket(AF_INET, SOCK_STREAM)
    sock.setsockopt(SOL_SOCKET, SO_REUSEADDR, 1)
    sock.bind(address)
    sock.listen(5)
    while True:
        yield 'recv', sock
        client, addr = sock.accept()
        tasks.append(handler(client, addr))

def echo_handler(client, address):
    print('Connection from', address)
    while True:
        yield 'recv', client
        data = client.recv(1000)
        if not data:
            break
        yield 'send', client
        client.send(b'GOT:', data)
    print('Coexión cerradad')

Crear una clase GenSocket que Limpia las sentencias yield y permite reescribir el servidor de forma más sencilla, como se indica a continuación:

def tcp_server(address, handler):
    sock = GenSocket(socket(AF_INET, SOCK_STREAM))
    sock.setsockopt(SOL_SOCKET, SO_REUSEADDR, 1)
    sock.bind(address)
    sock.listen(5)
    while True:
        client, addr = yield from sock.accept()
        tasks.append(handler(client, addr))

def echo_handler(client, address):
    print('Connection from', address)
    while True:
        data = yield from client.recv(1000)
        if not data:
            break
        yield from client.send(b'GOT:', data)
    print('Conexión cerrada')

(c) Async/Await

Tome la clase GenSocket que acaba de crear y envuelva todos los métodos que usan yield con el decorador @coroutine del módulo types.

from types import coroutine
...

class GenSocket:
    def __init__(self, sock):
        self.sock = sock

    @coroutine
    def accept(self):
        yield 'recv', self.sock
        client, addr = self.sock.accept()
        return GenSocket(client), addr

    @coroutine
    def recv(self, maxsize):
        yield 'recv', self.sock
        return self.sock.recv(maxsize)

    @coroutine
    def send(self, data):
        yield 'send', self.sock
        return self.sock.send(data)

    def __getattr__(self, name):
        return getattr(self.sock, name)

Ahora, reescribe el código de tu servidor para usar funciones async y sentencias await de la siguiente manera:

async def tcp_server(address, handler):
    sock = GenSocket(socket(AF_INET, SOCK_STREAM))
    sock.setsockopt(SOL_SOCKET, SO_REUSEADDR, 1)
    sock.bind(address)
    sock.listen(5)
    while True:
        client, addr = await sock.accept()
        tasks.append(handler(client, addr))

async def echo_handler(client, address):
    print('Connection from', address)
    while True:
        data = await client.recv(1000)
        if not data:
            break
        await client.send(b'GOT:', data)
    print('Conexión cerrada')
