Ejercicio 4.1

Objetivos:

  • Aprender más sobre cómo se representan los objetos.
  • Aprender cómo funciona la asignación y búsqueda de atributos.
  • Comprender mejor el rol de una definición de clase

Archivos creados: Ninguno

Archivos modificados: Ninguno

Comience este ejercicio volviendo a una versión simple de la clase Stock que creó. En el mensaje interactivo, defina una nueva clase llamada SimpleStock que se vea así:

>>> class SimpleStock:
        def __init__(self, name, shares, price):
            self.name = name
            self.shares = shares
            self.price = price
        def cost(self):
            return self.shares * self.price

>>>

Una vez que haya definido esta clase, cree algunas instancias.

>>> goog = SimpleStock('GOOG',100,490.10)
>>> ibm = SimpleStock('IBM',50, 91.23)
>>>

(a) Representación de instancias

En el shell interactivo, inspeccione los diccionarios subyacentes de las dos instancias que creó:

>>> goog.__dict__
... observe el resultado ...
>>> ibm.__dict__
... observe el resultado ...
>>>

(b) Modificación de datos de instancia

Intente configurar un nuevo atributo en una de las instancias anteriores:

>>> goog.date = "6/11/2007"
>>> goog.__dict__
... observe el resultado ...
>>> ibm.__dict__
... observe el resultado ...
>>>

En el resultado anterior, notarás que la instancia goog tiene un atributo date mientras que la instancia ibm no lo tiene. Es importante notar que Python realmente no impone ninguna restricción a los atributos. Por ejemplo, los atributos de una instancia no están limitados a los configurados en el método __init__().

En lugar de configurar un atributo, intenta colocar un nuevo valor directamente en el objeto __dict__:

>>> goog.__dict__['time'] = '9:45am'
>>> goog.time
'9:45am'
>>>

Aquí, realmente notas el hecho de que una instancia es una capa sobre un diccionario.

(c) El rol de las clases

Las definiciones que conforman una definición de clase son compartidas por todas las instancias de esa clase. Tenga en cuenta que todas las instancias tienen un enlace a su clase asociada:

>>> goog.__class__
... observe la salida ...
>>> ibm.__class__
... observe la salida ...
>>>

Intente llamar a un método en las instancias:

>>> goog.cost()
49010.0
>>> ibm.cost()
4561.5
>>>

Observe que el nombre 'cost' no está definido ni en goog.__dict__ ni en ibm.__dict__. En cambio, lo proporciona el diccionario de clases. Pruebe esto:

>>> SimpleStock.__dict__['cost']
... observe la salida...
>>>

Intente llamar al método cost() directamente a través del diccionario:

>>> SimpleStock.__dict__['cost'](goog)
49010.00
>>> SimpleStock.__dict__['cost'](ibm)
4561.5
>>>

Observe cómo está llamando a la función definida en la definición de clase y cómo el argumento self obtiene la instancia.

Si agrega un nuevo valor a la clase, se convierte en una variable de clase que es visible para todas las instancias. Pruébelo:

>>> SimpleStock.spam = 42
>>> ibm.spam
42
>>> goog.spam
42
>>>

Observe que spam no es parte del diccionario de instancias.

>>> ibm.__dict__
... observe la salida...
>>>

En cambio, es parte del diccionario de clases:

>>> SimpleStock.__dict__['spam']
42
>>>

Básicamente, esto es todo lo que una clase es realmente: es una colección de valores compartidos por instancias.
