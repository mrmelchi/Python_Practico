(a) Un generador simple

Si alguna vez desea personalizar la iteración, siempre debería considerar las funciones generadoras. Son fáciles de escribir: simplemente cree una función que ejecute la lógica de iteración deseada y use yield para emitir valores.

Por ejemplo, prueba este generador que te permite iterar sobre un rango de números con pasos fraccionarios (algo que no es compatible con la función range() integrada):

>>> def frange(start,stop,step):
        while start < stop:
            yield start
            start += step

>>> for x in frange(0, 2, 0.25):
        print(x, end=' ')

0 0.25 0.5 0.75 1.0 1.25 1.5 1.75
>>>

Iterar en un generador es una operación que se realiza una sola vez. Por ejemplo, esto es lo que sucede si intentas iterar dos veces:

>>> f = frange(0, 2, 0.25)
>>> for x in f:
        print(x, end=' ')

0 0.25 0.5 0.75 1.0 1.25 1.5 1.75
>>> for x in f:
        print(x, end=' ')

>>>

Si quieres iterar sobre la misma secuencia, debes recrear el generador llamando de nuevo a frange(). Alternativamente, podrías empaquetar todo en una clase:

>>> class FRange:
        def __init__(self, start, stop, step):
            self.start = start
            self.stop = stop
            self.step = step
        def __iter__(self):
            n = self.start
            while n < self.stop:
                yield n
                n += self.step

>>> f = FRange(0, 2, 0.25)
>>> for x in f:
        print(x, end=' ')

0 0.25 0.5 0.75 1.0 1.25 1.5 1.75
>>> for x in f:
        print(x, end=' ')

0 0.25 0.5 0.75 1.0 1.25 1.5 1.75

(b) Añadiendo iteración a objetos

Si ha creado una clase personalizada, puede configurarla para que admita iteraciones definiendo un método especial __iter__(). __iter__() devuelve un iterador como resultado. Como se muestra en el ejemplo anterior, una forma sencilla de hacerlo es definir __iter__() como generador.

En ejercicios anteriores, definió una clase base Structure. Añada un método __iter__() a esta clase que genere los valores de los atributos en orden. Por ejemplo:

class Structure(metaclass=StructureMeta):
    ...
    def __iter__(self):
        for name in self._fields:
            yield getattr(self, name)
    ...

Una vez hecho esto, debería poder iterar sobre los atributos de instancia de la siguiente manera:

>>> from stock import Stock
>>> s = Stock('GOOG', 100, 490.1)
>>> for val in s:
        print(val)
GOOG
100
490.1
>>>

(c) El sorprendente poder de la iteración

Python utiliza la iteración de maneras inesperadas. Una vez que haya añadido __iter__() a la clase Structure, descubrirá que es fácil realizar todo tipo de operaciones nuevas. Por ejemplo, conversiones a secuencias y desempaquetado:

>>> s = Stock('GOOG', 100, 490.1)
>>> list(s)
['GOOG', 100, 490.1]
>>> tuple(s)
('GOOG', 100, 490.1)
>>> name, shares, price = s
>>> name
'GOOG'
>>> shares
100
>>> price
490.1
>>>

Ya que estamos, podemos agregar un operador de comparación a nuestra clase Structure:

# structure.py
class Structure(metaclass=StructureMeta):
    ...
    def __eq__(self, other):
        return isinstance(other, type(self)) and tuple(self) == tuple(other)
    ...

Ahora debería poder comparar objetos:

>>> a = Stock('GOOG', 100, 490.1)
>>> b = Stock('GOOG', 100, 490.1)
>>> a == b
True
>>>

(d) Monitoreo de una fuente de datos en streaming

Los generadores también pueden ser una forma útil de producir un flujo de datos. En esta parte, exploraremos esta idea escribiendo un generador para monitorear un archivo de registro. Para comenzar, siga atentamente las siguientes instrucciones.

El programa Data/stocksim.py simula datos del mercado de valores. Como salida, el programa escribe constantemente datos en tiempo real en un archivo stocklog.csv. En una ventana de comandos (no en modo inactivo), acceda al directorio Data/ y ejecute este programa:

% python3 stocksim.py

Si usa Windows, simplemente localice el programa stocksim.py y haga doble clic en él para ejecutarlo. Ahora, olvídese de este programa (simplemente déjelo ejecutar). De nuevo, deje que este programa se ejecute en segundo plano; se ejecutará durante varias horas (no debería tener que preocuparse por ello).

Una vez que el programa anterior se esté ejecutando, escribamos un pequeño programa para abrir el archivo, buscar hasta el final y observar la nueva salida. Cree un archivo follow.py y escriba este código en él:

# follow.py
import os
import time
f = open('Data/stocklog.csv')
f.seek(0, os.SEEK_END)   # Move file pointer 0 bytes from end of file

while True:
    line = f.readline()
    if line == '':
        time.sleep(0.1)   # Sleep briefly and retry
        continue
    fields = line.split(',')
    name = fields[0].strip('"')
    price = float(fields[1])
    change = float(fields[4])
    if change < 0:
        print('%10s %10.2f %10.2f' % (name, price, change))

Si ejecuta el programa, verá un teletipo de acciones en tiempo real. En realidad, este código es similar al comando tail -f de Unix que se usa para ver un registro. Archivo.

Nota: El uso del método readline() en este ejemplo es algo inusual, ya que no es la forma habitual de leer líneas de un archivo (normalmente se usaría un bucle for). Sin embargo, en este caso, lo usamos para sondear repetidamente el final del archivo y comprobar si se han añadido más datos (readline() devolverá datos nuevos o una cadena vacía).

Si observa el código con atención, la primera parte produce líneas de datos, mientras que las sentencias al final del bucle while consumen los datos. Una característica importante de las funciones generadoras es que se puede trasladar todo el código de producción de datos a una función reutilizable.

Modifique el código para que la lectura del archivo la realice la función generadora follow(filename). Haz que el siguiente código funcione:

>>> for line in follow('Data/stocklog.csv'):
          print(line, end='')

... Deberías ver las líneas de salida generadas aquí...

Modifica el código del ticker de acciones para que se vea así:

for line in follow('Data/stocklog.csv'):
    fields = line.split(',')
    name = fields[0].strip('"')
    price = float(fields[1])
    change = float(fields[4])
    if change < 0:
        print('%10s %10.2f %10.2f' % (name, price, change))

Discusión

Acaba de ocurrir algo muy potente. Has movido un patrón de iteración interesante (leer líneas al final de un archivo) a su propia función. La función follow() ahora es así Una utilidad de propósito general que puedes usar en cualquier programa. Por ejemplo, puedes usarla para ver registros de servidores, registros de depuración y otras fuentes de datos similares. ¡Genial!
