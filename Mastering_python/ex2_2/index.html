Ejercicio 2.2

Objetivos:

  • Trabajar con varios contenedores
  • Comprensiones de listas/conjuntos/diccionarios
  • Módulo de colecciones
  • Desafío de análisis de datos

La mayoría de los programadores de Python están familiarizados con listas, diccionarios, tuplas y otros tipos de datos básicos. En este ejercicio, pondremos ese conocimiento en práctica para resolver varios problemas de análisis de datos.

(a) Preliminares

Para comenzar, revisemos algunos conceptos básicos con un conjunto de datos un poco más simple: una cartera de tenencias de acciones. Cree un archivo readport.py y coloque este código en él:

# readport.py

import csv

# Una función que lee un archivo en una lista de diccionarios
def read_portfolio(filename):
    portfolio = []
    with open(filename) as f:
        rows = csv.reader(f)
        headers = next(rows)
        for row in rows:
            record = {
                'name' : row[0],
                'shares' : int(row[1]),
                'price' : float(row[2])
            }
            portfolio.append(record)
    return portfolio

Este archivo lee algunos datos simples del mercado de valores en el archivo Data/portfolio.csv. Utilice la función para leer el archivo y ver los resultados:

>>> portfolio = read_portfolio('Data/portfolio.csv')
>>> from pprint import pprint
>>> pprint(portfolio)
[{'name': 'AA', 'price': 32.2, 'shares': 100},
 {'name': 'IBM', 'price': 91.1, 'shares': 50},
 {'name': 'CAT', 'price': 83.44, 'shares': 150},
 {'name': 'MSFT', 'price': 51.23, 'shares': 200},
 {'name': 'GE', 'price': 40.37, 'shares': 95},
 {'name': 'MSFT', 'price': 65.1, 'shares': 50},
 {'name': 'IBM', 'price': 70.44, 'shares': 100}]
>>>

En estos datos, cada fila consta de un nombre de acción, una cantidad de acciones en posesión y un precio de compra. Hay varias entradas para ciertos nombres de acciones, como MSFT e IBM.

(b) Comprensiones

Las comprensiones de listas, conjuntos y diccionarios pueden ser una herramienta útil para manipular datos. Por ejemplo, prueba estas operaciones:

>>> # Encuentra todas las tenencias de más de 100 acciones
>>> [s for s in portfolio if s['shares'] > 100]
[{'name': 'CAT', 'shares': 150, 'price': 83.44}, 
 {'name': 'MSFT', 'shares': 200, 'price': 51.23}]

>>> # Calcula el costo total (acciones * precio)
>>> sum([s['shares']*s['price'] for s in portfolio])
44671.15
>>>

>>> # Encuentra todos los nombres de acciones únicos (`set`)
>>> { s['name'] for s in portfolio }
{'MSFT', 'IBM', 'AA', 'GE', 'CAT'}
>>>

>>> # Cuenta el total de acciones de cada una de las acciones
>>> totals = { s['name']: 0 for s in portfolio }
>>> for s in portfolio:
        totals[s['name']] += s['shares']

>>> totals
{'AA': 100, 'IBM': 150, 'CAT': 150, 'MSFT': 250, 'GE': 95}
>>>

(c) Colecciones

El módulo collections tiene una variedad de clases para una manipulación de datos más especializada. Por ejemplo, el último ejemplo se podría resolver con un Counter como este:

>>> from collections import Counter
>>> totals = Counter()
>>> for s in portfolio:
        totals[s['name']] += s['shares']

>>> totals
Counter({'MSFT': 250, 'IBM': 150, 'CAT': 150, 'AA': 100, 'GE': 95})
>>>

Los contadores son interesantes porque admiten otros tipos de operaciones, como la clasificación y las matemáticas. Por ejemplo:

>>> # Obtener las dos tenencias más comunes
>>> totals.most_common(2)
[('MSFT', 250), ('IBM', 150)]
>>>

>>> # Sumando contadores
>>> more = Counter()
>>> more['IBM'] = 75
>>> more['AA'] = 200
>>> more['ACME'] = 30
>>> more
Counter({'AA': 200, 'IBM': 75, 'ACME': 30})
>>> totals
Counter({'MSFT': 250, 'IBM': 150, 'CAT': 150, 'AA': 100, 'GE': 95})
>>> totals + more
Counter({'AA': 300, 'MSFT': 250, 'IBM': 225, 'CAT': 150, 'GE': 95, 'ACME': 30})
>>>

El objeto defaultdict se puede utilizar para agrupar datos. Por ejemplo, supongamos que desea facilitar la búsqueda de todas las entradas coincidentes para un nombre determinado, como IBM. Pruebe esto:

>>> from collections import defaultdict
>>> byname = defaultdict(list)
>>> for s in portfolio:
        byname[s['name']].append(s)

>>> byname['IBM']
[{'name': 'IBM', 'shares': 50, 'price': 91.1}, {'name': 'IBM', 'shares': 100, 'price': 70.44}]
>>> byname['AA']
[{'name': 'AA', 'shares': 100, 'price': 32.2}]
>>>

La característica clave que hace que esto funcione es que un defaultdict inicializa automáticamente los elementos por usted, lo que permite que se combinen la inserción de un nuevo elemento y una operación append().

(d) Desafío de análisis de datos

En el último ejercicio, acabas de escribir un código para leer datos CSV relacionados con la Autoridad de Tránsito de Chicago. Por ejemplo, puedes obtener los datos como diccionarios de esta manera:

>>> import readrides
>>> rows = readrides.read_rides_as_dicts('Data/ctabus.csv')
>>>

Sería una pena hacer todo ese trabajo y luego no hacer nada con los datos.

En este ejercicio, tu tarea es la siguiente: escribe un programa para responder las siguientes tres preguntas:

  1. ¿Cuántas rutas de autobús existen en Chicago?

  2. ¿Cuántas personas viajaron en el autobús número 22 el 2 de febrero de 2011? ¿Qué hay de cualquier ruta en cualquier fecha que elijas?

  3. ¿Cuál es el número total de viajes en cada ruta de autobús?

  4. ¿Cuáles son las cinco rutas de autobús que tuvieron el mayor aumento de pasajeros en diez años, desde 2001 hasta 2011?

Puede utilizar cualquier técnica para responder las preguntas anteriores, siempre que sea parte de la biblioteca estándar de Python (es decir, tipos de datos integrados, módulos de la biblioteca estándar, etc.).
