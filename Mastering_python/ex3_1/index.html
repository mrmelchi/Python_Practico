Ejercicio 3.1

Objetivos:

  • Definir una clase simple

Archivos modificados: stock.py

En el Ejercicio 1.5, definió una clase simple Stock para representar una tenencia de acciones. En este ejercicio, simplemente vamos a agregar algunas características a esa clase y también escribir algunas funciones de utilidad.

(a) Agregar un nuevo método

Agregue un nuevo método sell(nshares) a Stock que venda una cierta cantidad de acciones al disminuir el recuento de acciones. Haga que funcione de esta manera:

>>> from stock import Stock
>>> s = Stock('GOOG',100,490.10)
>>> s.shares
100
>>> s.sell(25)
>>> s.shares
75
>>>

(b) Lectura de una cartera

Agregue una función read_portfolio() a su programa stock.py que lea un archivo de datos de cartera en una lista de objetos Stock. Así es como debería funcionar:

>>> import stock
>>> portfolio = stock.read_portfolio('Data/portfolio.csv')
>>> for s in portfolio:
...     print(s)
... 
<stock.Stock object at 0x000001F3ED0BCD70>
<stock.Stock object at 0x000001F3ED04A710>
<stock.Stock object at 0x000001F3ED04A850>
<stock.Stock object at 0x000001F3ED0C8510>
<stock.Stock object at 0x000001F3ED0C8640>
<stock.Stock object at 0x000001F3ED033650>
<stock.Stock object at 0x000001F3ED04D150>
>>>

Ya escribiste una función similar como parte del Ejercicio 2.3. Discusión sobre el diseño: ¿debería ser read_portfolio() una función independiente o parte de la definición de la clase?

(c) Impresión de una tabla

Tome los datos leídos en la parte (b) y utilícelos para crear una tabla con un formato adecuado. Por ejemplo:

>>> portfolio = stock.read_portfolio('Data/portfolio.csv')
>>> for s in portfolio:
           print('%10s %10d %10.2f' % (s.name, s.shares, s.price))

        AA        100      32.20
       IBM         50      91.10
       CAT        150      83.44
      MSFT        200      51.23
        GE         95      40.37
      MSFT         50      65.10
       IBM        100      70.44
>>>

Tome este código y colóquelo en una función print_portfolio() que produce la misma salida, pero además agrega algunos encabezados de tabla. Por ejemplo:

>>> portfolio = stock.read_portfolio('Data/portfolio.csv')
>>> stock.print_portfolio(portfolio)
      name     shares      price
---------- ---------- ---------- 
        AA        100      32.20
       IBM         50      91.10
       CAT        150      83.44
      MSFT        200      51.23
        GE         95      40.37
      MSFT         50      65.10
       IBM        100      70.44
>>>
