Parte 1: Números

Los cálculos numéricos funcionan de forma similar a como se esperaría en Python. Por ejemplo:

>>> 3 + 4*5
23
>>> 23.45 / 1e-02
2345.0
>>>

Ten en cuenta que la división de números enteros es diferente en Python 2 y Python 3.

>>> 7 / 4 # En Python 2, esto se trunca a 1
1.75
>>> 7 // 4 # Truncando la división
1
>>>

Si quieres el comportamiento de Python 3 en Python 2, haz lo siguiente:

>>> from __future__ import division
>>> 7 / 4
1.75
>>> 7 // 4 # Truncando la división
1
>>>

Los números tienen un pequeño conjunto de métodos, muchos de los cuales son bastante recientes y se pasan por alto. Incluso los programadores de Python experimentados pueden hacer esto. Pruebe algunas de ellas.

>>> x = 1172.5
>>> x.as_integer_ratio()
(2345, 2)
>>> x.is_integer()
False
>>> y = 12345
>>> y.numerator
12345
>>> y.denominator
1
>>> y.bit_length()
14
>>>

Parte 2: Manipulación de cadenas

Defina una cadena que contenga una serie de symbols bursátiles como esta:

>>> symbols = 'AAPL IBM MSFT YHOO SCO'

Ahora, experimentemos con diferentes operaciones de cadenas:

(a) Extracción de caracteres individuales y subcadenas

Las cadenas son matrices de caracteres. Intente extraer algunos caracteres:

>>> symbols[0]
'A'
>>> symbols[1]
'A'
>>> symbols[2]
'P'
>>> symbols[-1] # Último carácter
'O'
>>> symbols[-2] # 2.º carácter desde el último
'C'
>>>

Intente extraer algunas porciones:

>>> symbols[:4]
'AAPL'
>>> symbols[-3:]
'SCO'
>>> symbols[5:8]
'IBM'
>>>

(b) Cadenas como objetos de solo lectura

Las cadenas son de solo lectura. Verifique esto intentando cambiar el primer carácter de símbolos a una 'a' minúscula.

>>> symbols[0] = 'a'
Traceback (última llamada más reciente):
Archivo "<stdin>", línea 1, en <módulo>
TypeError: el objeto 'str' no admite la asignación de elementos
>>>

(c) Concatenación de cadenas

Aunque los datos de cadena son de solo lectura, siempre puede reasignar una variable a una cadena recién creada. Pruebe la siguiente declaración que concatena un nuevo símbolo "GOOG" al final de symbols:

>>> symbols += ' GOOG'
>>> symbols
... observe el resultado ...

Ahora, intente agregar "HPQ" al comienzo de symbols de esta manera:

>>> symbols = 'HPQ ' + symbols
>>> symbols
... observe el resultado ...

Debe notarse que en ambos ejemplos, la cadena original symbols NO se modifica "en el lugar". En cambio, se crea una cadena completamente nueva. El nombre de la variable symbols solo se vincula al resultado. Luego, la cadena anterior se destruye ya que ya no se usa.

(d) Prueba de membresía (prueba de subcadenas)

Experimente con el operador in para verificar subcadenas. En el indicador interactivo, pruebe estas operaciones:

>>> 'IBM' en symbols
True
>>> 'AA' en symbols
True
>>> 'CAT' en symbols
False
>>>

Asegúrese de comprender por qué la comprobación de "AA" devolvió True.

(e) Métodos de cadena

En el indicador interactivo de Python, intente experimentar con algunos de los métodos de cadena.

>>> symbols.lower()
'hpq aapl ibm msft yhoo sco goog'
>>> symbols
'HPQ AAPL IBM MSFT YHOO SCO GOOG'

Recuerde, las cadenas siempre son de solo lectura. Si desea guardar el resultado de una operación, debe colocarlo en una variable:

>>> lowersyms = symbols.lower()
>>> lowersyms
'hpq aapl ibm msft yhoo sco goog'
>>>

Pruebe con más operaciones:

>>> symbols.find('MSFT')
13
>>> symbol[13:17]
'MSFT'
>>> symbols = symbols.replace('SCO','')
>>> symbols
'HPQ AAPL IBM MSFT YHOO GOOG'
>>>

Parte 3: Manipulación de listas

En la primera parte, trabajó con cadenas que contienen symbos bursátiles. Por ejemplo:

>>> symbols = 'HPQ AAPL IBM MSFT YHOO GOOG'
>>>

Defina la variable anterior y divídala en una lista de nombres utilizando la operación split() de cadenas:

>>> symlist = symbols.split()
>>> symlist
['HPQ', 'AAPL', 'IBM', 'MSFT', 'YHOO', 'GOOG' ]
>>>

(a) Extracción y reasignación de elementos de lista

Las listas funcionan como matrices donde puede buscar y modificar elementos por índice numérico. Pruebe algunas búsquedas:

>>> symlist[0]
'HPQ'
>>> symlist[1]
'AAPL'
>>> symlist[-1]
'GOOG'
>>> symlist[-2]
'YHOO'
>>>

Intente reasignar uno de los elementos:

>>> symlist[2] = 'AIG'
>>> symlist
['HPQ', 'AAPL', 'AIG', 'MSFT', 'YHOO', 'GOOG' ]
>>>

(b) Recorrer los elementos de una lista

El bucle for funciona recorriendo los datos de una secuencia, como una lista. Mira esto escribiendo el siguiente bucle y observando lo que sucede:

>>> for s in symlist:
        print('s =', s)

... mira el resultado...

(c) Pruebas de pertenencia

Usa el operador in para verificar si 'AIG','AA' y 'CAT' están en la lista de símbolos.

>>> 'AIG' in symlist
True
>>> 'AA' in symlist
False
>>>

Utilice el método append() para agregar el símbolo 'RHT' al final de symlist.

>>> symlist.append('RHT')
>>> symlist
['HPQ', 'AAPL', 'AIG', 'MSFT', 'YHOO', 'GOOG', 'RHT']
>>>

Utilice el método insert() para insertar el símbolo 'AA' como el segundo elemento de la lista.

>>> symlist.insert(1,'AA')
>>> symlist
['HPQ', 'AA', 'AAPL', 'AIG', 'MSFT', 'YHOO', 'GOOG', 'RHT']
>>>

Utilice el método remove() para eliminar 'MSFT' de la lista.

>>> symlist.remove('MSFT')
>>> symlist
['HPQ', 'AA', 'AAPL', 'AIG', 'YHOO', 'GOOG', 'RHT']

Intenta llamar a remove() nuevamente para ver qué sucede si no se puede encontrar el elemento.

>>> symlist.remove('MSFT')
... observa lo que sucede...
>>>

Usa el método index() para encontrar la posición de 'YHOO' en la lista.

>>> symlist.index('YHOO')
4
>>> symlist[4]
'YHOO'
>>>

(e) Ordenamiento de listas

¿Quieres ordenar una lista? Usa el método sort(). Pruébelo:

>>> symlist.sort()
>>> symlist
['AA', 'AAPL', 'AIG', 'GOOG', 'HPQ', 'RHT', 'YHOO']
>>>

¿Quiere ordenar en sentido inverso? Pruebe esto:

>>> symlist.sort(reverse=True)
>>> symlist
['YHOO', 'RHT', 'HPQ', 'GOOG', 'AIG', 'AAPL', 'AA']
>>>

Nota: Ordenar una lista modifica su contenido "en el lugar". Es decir, los elementos de la lista se reordenan, pero no se crea una nueva lista como resultado.

(f) Listas de cualquier cosa

Las listas pueden contener cualquier tipo de objeto, incluidas otras listas (por ejemplo, listas anidadas). Pruebe esto:

>>> nums = [101,102,103]
>>> items = [symlist, nums]
>>> items
[['YHOO', 'RHT', 'HPQ', 'GOOG', 'AIG', 'AAPL', 'AA'], [101, 102, 103]]

Preste mucha atención al resultado anterior. items es una lista con dos elementos. Cada elemento es una lista.

Pruebe algunas búsquedas de listas anidadas:

>>> items[0]
['YHOO', 'RHT', 'HPQ', 'GOOG', 'AIG', 'AAPL', 'AA']
>>> items[0][1]
'RHT'
>>> items[0][1][2]
'T'
>>> items[1]
[101, 102, 103]
>>> items[1][1]
102
>>>

Parte 4: Diccionarios

En las últimas partes, simplemente trabajó con símbolos bursátiles. Sin embargo, suponga que desea asignar símbolos bursátiles a otros datos como el precio. Utilice un diccionario:

>>> prices = { 'IBM': 91.1, 'GOOG': 490.1, 'AAPL':312.23 }
>>>

Un diccionario asigna claves a valores. Aquí se explica cómo acceder:

>>> prices['IBM']
91.1
>>> prices['IBM'] = 123.45
>>> prices['HPQ'] = 26.15
>>> prices
{'GOOG': 490.1, 'AAPL': 312.23, 'IBM': 123.45, 'HPQ': 26.15}
>>>

Para obtener una lista de claves, utilice esto:

>>> list(prices)
['GOOG', 'AAPL', 'IBM', 'HPQ']
>>>

Para eliminar un valor, utilice del

>>> del prices['AAPL']
>>> prices
{'GOOG': 490.1, 'IBM': 123.45, 'HPQ': 26.15}
>>>
