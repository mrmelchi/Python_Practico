Ejercicio 9.3

Objetivos:

  • Aprender a controlar símbolos y combinar submódulos
  • Aprender a dividir módulos

Un aspecto potencialmente molesto de los paquetes es que complican las sentencias de importación. Por ejemplo, en el programa stock.py, ahora tiene sentencias de importación como las siguientes:

from structly.structure import Structure
from structly.reader import read_csv_as_instances
from structly.tableformat import create_formatter, print_table

Si el paquete está pensado para usarse como un todo unificado, podría ser más sensato (y más sencillo) consolidarlo todo en un único paquete de nivel superior. Hagamos esto:

(a) Control de los símbolos exportados

Modifique todos los submódulos del paquete structly para que definan explícitamente una variable __all__ que exporte los símbolos seleccionados. Específicamente:

  • structure.py debería exportar Structure
  • reader.py debería exportar todas las funciones read_csv_as_*()
  • tableformat.py exporta create_formatter() y print_table()

Ahora, en el archivo __init__.py, unifique todos los submódulos de la siguiente manera:

# structly/__init__.py

from .structure import *
from .reader import *
from .tableformat import *

Una vez hecho esto, debería poder importar todo desde un único módulo lógico:

# stock.py

from structly import Structure

class Stock(Structure):
    name = String()
    shares = PositiveInteger()
    price = PositiveFloat()

    @property
    def cost(self):
        return self.shares * self.price

    def sell(self, nshares: PositiveInteger):
        self.shares -= nshares

if __name__ == '__main__':
    from structly import read_csv_as_instances, create_formatter, print_table
    portfolio = read_csv_as_instances('Data/portfolio.csv', Stock)
    formatter = create_formatter('text')
    print_table(portfolio, ['name','shares','price'], formatter)

(b) Exportación completa

En structly/__init__.py, defina la variable __all__ que contiene todos los símbolos exportados. Una vez hecho esto, deberías poder simplificar aún más el archivo stock.py:

# stock.py

from structly import *

class Stock(Structure):
    name = String()
    shares = PositiveInteger()
    price = PositiveFloat()

    @property
    def cost(self):
        return self.shares * self.price

    def sell(self, nshares: PositiveInteger):
        self.shares -= nshares

if __name__ == '__main__':
    portfolio = read_csv_as_instances('Data/portfolio.csv', Stock)
    formatter = create_formatter('text')
    print_table(portfolio, ['name','shares','price'], formatter)

Aparte, el uso de la instrucción from module import * generalmente está mal visto en la comunidad Python, especialmente si No estás seguro de lo que haces. Dicho esto, hay situaciones en las que suele ser útil. Por ejemplo, si un paquete define una gran cantidad de símbolos o constantes de uso común, podría ser útil usarlo.

(c) División de módulos

El archivo structly/tableformat.py contiene código para crear tablas en diferentes formatos. Específicamente:

  • Una clase base TableFormatter.
  • Una clase TextTableFormatter.
  • Una clase CSVTableFormatter.
  • Una clase HTMLTableFormatter.

En lugar de tener todas estas clases en un solo archivo .py, quizás sería más conveniente mover cada formateador concreto a su propio archivo. Para ello, dividiremos el archivo tableformat.py en partes. Sigue estas instrucciones cuidadosamente:

Primero, elimina el directorio structly/__pycache__.

% cd structly
% rm -rf __pycache__

A continuación, cree el directorio structly/tableformat. Este directorio debe tener exactamente el mismo nombre que el módulo que reemplaza (tableformat.py).

bash % mkdir tableformat
bash %

Mueva el archivo tableformat.py original al nuevo directorio tableformat y renómbrelo formatter.py.

bash % mv tableformat.py tableformat/formatter.py
bash %

En el directorio tableformat, divida el código de tableformat.py en los siguientes archivos y directorios:

  • formatter.py - Contiene la clase base TableFormatter, mixins y varias funciones.
  • formats/text.py - Contiene la clase TextTableFormatter. - formats/csv.py - Contiene la clase CSVTableFormatter.
  • formats/html.py - Contiene la clase HTMLTableFormatter.

Agregue un archivo __init__.py a los directorios tableformat/ y tableformat/formats. Haga que tableformat/__init__.py exporte los mismos símbolos que el archivo tableformat.py original.

Después de realizar todos estos cambios, debería tener una estructura de paquete similar a la siguiente:

structly/
__init__.py
validate.py
reader.py
structure.py
tableformat/
__init__.py
formatter.py
forms/
__init__.py
text.py
csv.py
html.py

Para los usuarios, todo debería funcionar exactamente igual que antes. Por ejemplo, su archivo stock.py anterior debería funcionar:

# stock.py

from structly import *
