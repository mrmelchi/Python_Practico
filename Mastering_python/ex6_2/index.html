Ejercicio 6.2

Objetivos:

  • Aprender más sobre las reglas de alcance
  • Aprender algunos trucos de alcance

Archivos modificados: structure.py, stock.py

En el último ejercicio, creaste la clase Structure que facilitó la definición de estructuras de datos. Por ejemplo:

class Stock(Structure):
    _fields = ('name','shares','price')

Esto funciona bien, excepto que hay muchos aspectos extraños en la función __init__(). Por ejemplo, si solicitas ayuda usando help(Stock), no obtienes ninguna firma útil. Además, el paso de argumentos por palabra clave no funciona. Por ejemplo:

>>> help(Stock)
... observe la salida....

>>> s = Stock(name='GOOG', shares=100, price=490.1)
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
TypeError: __init__() got an unexpected keyword argument 'price'
>>>

En este ejercicio, analizaremos un enfoque diferente para el problema.

(a) Muéstrame tus variables locales

Primero, prueba un experimento definiendo la siguiente clase:

>>> class Stock:
        def __init__(self, name, shares, price):
            print(locals())

>>>

Ahora, intenta ejecutar esto:

>>> s = Stock('GOOG', 100, 490.1)
{'self': <__main__.Stock object at 0x100699b00>, 'price': 490.1, 'name': 'GOOG', 'shares': 100}
>>>

Observa cómo el diccionario de variables locales contiene todos los argumentos pasados ​​a __init__(). Es interesante. Ahora, defina las siguientes definiciones de función y clase:

>>> def _init(locs):
        self = locs.pop('self')
        for name, val in locs.items():
            setattr(self, name, val)

>>> class Stock:
        def __init__(self, name, shares, price):
            _init(locals())

En este código, la función _init() se usa para inicializar automáticamente un objeto a partir de un diccionario de variables locales pasadas. Verá que help(Stock) y los argumentos de palabras clave funcionan perfectamente.

>>> s = Stock(name='GOOG', price=490.1, shares=50)
>>> s.name
'GOOG'
>>> s.shares
50
>>> s.price
490.1
>>>

(b) Hackeo de marcos de pila

Una queja sobre la última parte es que la función __init__() ahora se ve bastante extraña con esa llamada a locals() insertada. Sin embargo, puedes solucionar esto si estás dispuesto a hackear un poco los marcos de pila. Prueba esta variante de la función _init():

>>> import sys
>>> def _init():
        locs = sys._getframe(1).f_locals   # Obtener las variables locales del                                                # invocador
        self = locs.pop('self')
        for name, val in locs.items():
            setattr(self, name, val)
>>>

En este código, las variables locales se extraen del marco de pila del invocador. Aquí tienes una definición de clase modificada:

>>> class Stock:
        def __init__(self, name, shares, price):
            _init()

>>> s = Stock('GOOG', 100, 490.1)
>>> s.name
'GOOG'
>>> s.shares
100
>>>

En este punto, probablemente te sientas un poco perturbado. Sí, acabas de escribir una función que accedió al marco de pila de otra función y examinó sus variables locales.

(c) En resumen

Tomando las ideas de las dos primeras partes, elimina el método __init__() que originalmente formaba parte de la clase Structure. A continuación, agregue un método _init() como este:

# structure.py
import sys

class Structure:
    ...
    @staticmethod
    def _init():
        locs = sys._getframe(1).f_locals
        self = locs.pop('self')
        for name, val in locs.items():
            setattr(self, name, val)
    ...

Nota: La razón por la que esto se define como un @staticmethod es que el argumento self se obtiene de las variables locales; no es necesario pasarlo adicionalmente como argumento al propio método (aunque esto es un poco sutil).

Ahora, modifica tu clase Stock para que se vea como la siguiente:

# stock.py
from structure import Structure

class Stock(Structure):
    _fields = ('name','shares','price')
    def __init__(self, name, shares, price):
        self._init()

    @property
    def cost(self):
        return self.shares * self.price

    def sell(self, shares):
        self.shares -= shares

Verifica que la clase funcione correctamente, admita argumentos de palabras clave y tenga una firma de ayuda adecuada.

>>> s = Stock(name='GOOG', price=490.1, shares=50)
>>> s.name
'GOOG'
>>> s.shares
50
>>> s.price
490.1
>>> help(Stock)
... observa el resultado...
>>>

Ejecuta tus pruebas unitarias en teststock.py de nuevo. Deberías ver al menos una prueba más completa. ¡Genial! En ​​este punto, parecerá que hemos dado un gran paso atrás. Las clases no solo necesitan el método __init__(), sino también la variable _fields para que funcionen algunos de los otros métodos (__repr__() y __setattr__()). Además, el uso de self._init() parece bastante complicado. Trabajaremos en esto, pero ten paciencia.
