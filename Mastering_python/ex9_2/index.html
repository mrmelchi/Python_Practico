Ejercicio 9.2

Objetivos:

  • Aprender a crear un paquete de Python

Nota

Este ejercicio consiste principalmente en copiar archivos en el sistema de archivos. No debería requerir mucha programación.

(a) Creación de un paquete

En ejercicios anteriores, creaste los siguientes archivos relacionados con estructuras con verificación de tipos, lectura de datos y creación de tablas:

  • structure.py
  • validate.py
  • reader.py
  • tableformat.py

Tu tarea consiste en mover todos estos archivos a un paquete llamado structly. Para ello, siga estos pasos:

  • Cree un directorio llamado structly
  • Cree un archivo vacío __init__.py y colóquelo en el directorio structly
  • Mueva los archivos structure.py, validate.py, reader.py y tableformat.py al directorio structly.
  • Corrija cualquier declaración de importación entre módulos (en concreto, el módulo structure depende de validate).

Una vez hecho esto, modifica el programa stock.py para que se vea exactamente así y funcione:

# stock.py

from structly.structure import Structure

class Stock(Structure):
    name = String()
    shares = PositiveInteger()
    price = PositiveFloat()

    @property
    def cost(self):
        return self.shares * self.price

    def sell(self, nshares: PositiveInteger):
        self.shares -= nshares

if __name__ == '__main__':
    from structly.reader import read_csv_as_instances
    from structly.tableformat import create_formatter, print_table
    portfolio = read_csv_as_instances('Data/portfolio.csv', Stock)
    formatter = create_formatter('text')
    print_table(portfolio, ['name','shares','price'], formatter)
