Ejercicio 1.6

Objetivos:

  • Definición de módulos
  • Uso de la declaración import

Archivos creados: Ninguno

Nota: Para este ejercicio que involucra módulos, es muy importante asegurarse de que está ejecutando Python en un entorno adecuado. Es posible que deba verificar el valor de sys.path si no puede hacer que funcionen las declaraciones import. Pida ayuda si todo parece estar roto.

Antes de comenzar este ejercicio, primero reinicie su sesión de intérprete de Python. Si usa IDLE, haga clic en la ventana del shell y busque la opción de menú "Shell > Reiniciar Shell". Deberías recibir un mensaje como este:

>>> ##################== RESTART ##################==
>>>

Si estás usando Unix, simplemente sal de Python y reinicia el intérprete.

(a) Uso de la declaración de importación

En ejercicios anteriores, escribiste dos programas pcost.py y stock.py. Utilice la declaración import para cargar estos programas y utilizar su funcionalidad:

>>> import pcost
44671.15
>>> pcost.portfolio_cost('Data/portfolio2.dat')
19908.75
>>> from stock import Stock
>>> s = Stock('GOOG', 100, 490.10)
>>> s.name
'GOOG'
>>> s.cost()
49010.0
>>>

Si no puede hacer que las declaraciones anteriores funcionen, es posible que haya colocado sus programas en un directorio extraño. Asegúrese de estar ejecutando Python en el mismo directorio que sus archivos o de que el directorio esté incluido en sys.path.

(b) Módulo principal

En su programa pcost.py, la última declaración llamó a una función e imprimió el resultado. Modifique el programa para que este paso solo se realice si el programa se ejecuta como el programa principal. Ahora, intente ejecutar el programa de dos maneras:

Primero, ejecute el programa como principal:

bash % python3 pcost.py
44671.25
bash %

A continuación, ejecute el programa como una importación de biblioteca. No debería ver ningún resultado.

>>> import pcost
>>>
