Ejercicio 7.4

Objetivos:

  • Aprender los pasos básicos para crear una clase.

Archivos modificados: validate.py, structure.py

En este ejercicio, analizamos la mecánica de la creación de clases.

(a) Creación de la clase

Recuerde que, en ejercicios anteriores, definimos una clase simple, Acciones, con este aspecto:

class Stock:
    def __init__(self,name,shares,price):
        self.name = name
        self.shares = shares
        self.price = price
    def cost(self):
        return self.shares*self.price
    def sell(self,nshares):
        self.shares -= nshares

Lo que haremos aquí es crear la clase manualmente. Comience definiendo los métodos como funciones normales de Python.

>>> def __init__(self,name,shares,price):
        self.name = name
        self.shares = shares
        self.price = price

>>> def cost(self):
        return self.shares*self.price

>>> def sell(self,nshares):
        self.shares -= nshares

>>>

A continuación, crea un diccionario de métodos:

```python
>>> methods = {
         '__init__' : __init__,
         'cost' : cost,
         'sell' : sell } 

>>>

Finalmente, crea el objeto de la clase Stock:

>>> Stock = type('Stock',(object,),methods)
>>> s = Stock('GOOG',100,490.10)
>>> s.name
'GOOG'
>>> s.cost()
49010.0
>>> s.sell(25)
>>> s.shares
75
>>>

¡Felicitaciones! Acabas de crear una clase. Una clase no es más que un nombre, una tupla de clases base y un diccionario que contiene todo el contenido de la clase. type() es un constructor que crea una clase automáticamente si proporcionas estas tres partes.

(b) Estructuras tipificadas

En el archivo structure.py, define la siguiente función:

# structure.py

...
def typed_structure(clsname, **validators):
    cls = type(clsname, (Structure,), validators)
    return cls

Esta función es similar a namedtuple() en que crea una clase. Pruébalo:

>>> from validate import String, PositiveInteger, PositiveFloat
>>> from structure import typed_structure
>>> Stock = typed_structure('Stock', name=String(), shares=PositiveInteger(), price=PositiveFloat())
>>> s = Stock('GOOG', 100, 490.1)
>>> s.name
'GOOG'
>>> s
Stock('GOOG', 100, 490.1)
>>>

Quizás sientas que se te está rompiendo la cabeza.

(c) Creación de muchas clases

Existen otras situaciones en las que el uso directo del constructor type() podría ser ventajoso. Considera este fragmento de código:

# validate.py
...

class Typed(Validator):
    expected_type = object
    @classmethod
    def check(cls, value):
        if not isinstance(value, cls.expected_type):
            raise TypeError(f'expected {cls.expected_type}')
        super().check(value)

class Integer(Typed):
    expected_type = int

class Float(Typed):
    expected_type = float

class String(Typed):
    expected_type = str
...

¡Vaya! ¡Qué fastidiosa y repetitiva es la última parte! Cámbielo para usar una tabla con las clases de tipos deseadas como esta:

# validate.py
...

_typed_classes = [
    ('Integer', int),
    ('Float', float),
    ('String', str) ]

globals().update((name, type(name, (Typed,), {'expected_type':ty}))
                 for name, ty in _typed_classes)

Ahora, si desea tener más clases de tipos, simplemente agréguelas a la tabla:

_typed_classes = [
    ('Integer', int),
    ('Float', float),
    ('Complex', complex),
    ('Decimal', decimal.Decimal),
    ('List', list),
    ('Bool', bool),
    ('String', str) ]

Admítelo, es genial y te ahorra mucho tiempo de escritura.
