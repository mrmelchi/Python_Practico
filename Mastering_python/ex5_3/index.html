(a) Uso de funciones de orden superior

Actualmente, el programa reader.py consta de dos funciones principales: csv_as_dicts() y csv_as_instances(). El código de estas dos funciones es prácticamente idéntico. Por ejemplo:

def csv_as_dicts(lines, types, *, headers=None):
    '''
    Convierte líneas de datos CSV en una lista de diccionarios

    '''
    records = []
    rows = csv.reader(lines)
    if headers is None:
        headers = next(rows)
    for row in rows:
        record = { name: func(val)
                   for name, func, val in zip(headers, types, row) }
        records.append(record)
    return records

def csv_as_instances(lines, cls, *, headers=None):
    '''
    Convierte líneas de datos CSV en una lista de instancias
    '''
    records = []
    rows = csv.reader(lines)
    if headers is None:
        headers = next(rows)
    for row in rows:
        record = cls.from_row(row)
        records.append(record)
    return records

Unifica el núcleo de estas funciones en una sola función convert_csv() que acepta una función de conversión definida por el usuario como argumento. Por ejemplo:

>>> def make_dict(headers, row):
        return dict(zip(headers, row))

>>> lines = open('Data/portfolio.csv')
>>> convert_csv(lines, make_dict)
[{'name': 'AA', 'shares': '100', 'price': '32.20'}, {'name': 'IBM', 'shares': '50', 'price': '91.10'}, 
 {'name': 'CAT', 'shares': '150', 'price': '83.44'}, {'name': 'MSFT', 'shares': '200', 'price': '51.23'}, 
 {'name': 'GE', 'shares': '95', 'price': '40.37'}, {'name': 'MSFT', 'shares': '50', 'price': '65.10'}, 
 {'name': 'IBM', 'shares': '100', 'price': '70.44'}]
>>>

Reescriba las funciones csv_as_dicts() y csv_as_instances() en función de la nueva función convert_csv().

(b) Mapeo

Una de las operaciones más comunes en programación funcional es map(), que mapea una función a los valores de una secuencia. Python tiene una función map() integrada que realiza esta función. Por ejemplo:

>>> nums = [1,2,3,4]
>>> squares = map(lambda x: x*x, nums)
>>> for n in squares:
        print(n)

1
4
9
16
>>>

map() produce un iterador, así que si quieres una lista, tendrás que crearla explícitamente:

>>> squares = list(map(lambda x: x*x, nums))
>>> squares
[1, 4, 9, 16]
>>>

Intenta usar map() en tu función convert_csv().
