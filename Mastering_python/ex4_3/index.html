Ejercicio 4.3

Objetivos:

  • Aprender sobre descriptores

Archivos creados: descrip.py

Archivos modificados: validate.py

(a) Descriptores en acción

Anteriormente, creaste una clase Stock que hacía uso de ranuras, propiedades y otras características. Todas estas características se implementan utilizando el protocolo de descriptor. Míralo en acción probando este simple experimento.

Primero, crea un objeto de stock e intenta buscar algunos atributos:

>>> s = Stock('GOOG', 100, 490.10)
>>> s.name
'GOOG'
>>> s.shares
100
>>>

Ahora, observa que estos atributos están en el diccionario de clases.

>>> Stock.__dict__.keys()
['sell', '__module__', '__weakref__', 'price', '_price', 'shares', '_shares',
'__slots__', 'cost', '__repr__', '__doc__', '__init__']
>>>

Pruebe estos pasos que ilustran cómo los descriptores obtienen y establecen valores en una instancia:

>>> q = Stock.__dict__['shares']
>>> q.__get__(s)
100
>>> q.__set__(s,75)
>>> s.shares
75
>>> q.__set__(s, '75')
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
  File "stock.py", line 23, in shares
    raise TypeError('Expected an integer')
TypeError: Expected an integer
>>>

La ejecución de __get__() y __set__() se produce automáticamente siempre que se accede a las instancias.

(b) Crea tu propio descriptor

Define la clase del descriptor a partir de las notas:

# descrip.py

class Descriptor:
    def __init__(self, name):
        self.name = name
    def __get__(self, instance, cls):
        print('%s:__get__' % self.name)
    def __set__(self, instance, value):
        print('%s:__set__ %s' % (self.name, value))
    def __delete__(self, instance):
        print('%s:__delete__' % self.name)

Ahora, intenta definir una clase simple que use este descriptor:

>>> class Foo:
        a = Descriptor('a')
        b = Descriptor('b')
        c = Descriptor('c')

>>> f = Foo()
>>> f
<__main__.Foo object at 0x38e130> <class __main__.Foo>
>>> f.a
a:__get__
>>> f.b
b:__get__
>>> f.a = 23
a:__set__ 23
>>> del f.a
a:__delete__
>>>

Considere el hecho de que ha capturado el operador de punto para un atributo específico.

(c) De validadores a descriptores

En el ejercicio anterior, escribió una serie de clases que podían realizar comprobaciones. Por ejemplo:

>>> PositiveInteger.check(10)
10
>>> PositiveInteger.check('10')
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
    raise TypeError('Expected %s' % cls.expected_type)
TypeError: expected <class 'int'>
>>> PositiveInteger.check(-10)

Puedes extender esto a los descriptores haciendo un cambio simple en la clase base Validator. Cámbielo por lo siguiente:

# validate.py

class Validator:
    def __init__(self, name):
        self.name = name

    @classmethod
    def check(cls, value):
        return value

    def __set__(self, instance, value):
        instance.__dict__[self.name] = self.check(value)

Nota: La falta del método __get__() en el descriptor significa que Python usará su implementación predeterminada de búsqueda de atributos. Esto requiere que el nombre suministrado coincida con el nombre usado en el diccionario de instancias.

No deberían ser necesarios otros cambios. Ahora, intenta modificar la clase Stock para usar los validadores como descriptores de esta manera:

class Stock:
    name   = String('name')
    shares = PositiveInteger('shares')
    price  = PositiveFloat('price')

    def __init__(self,name,shares,price):
        self.name = name
        self.shares = shares
        self.price = price

Verás que tu clase funciona de la misma manera que antes, implica mucho menos código y te brinda toda la verificación deseada:

>>> s = Stock('GOOG', 100, 490.10)
>>> s.name
'GOOG'
>>> s.shares
100
>>> s.shares = 75
>>> s.shares = '75'
... TypeError ...
>>> s.shares = -50
... ValueError ...
>>>

Esto es genial. Los descriptores le han permitido simplificar enormemente la implementación de la clase Stock. Este es el verdadero poder de los descriptores: obtiene un control de bajo nivel sobre el punto y puede usarlo para hacer cosas asombrosas.

(d) Corrección de los nombres

Una cosa molesta sobre los descriptores es la especificación redundante de nombres. Por ejemplo:

class Stock:
    ...
    shares = PositiveInteger('shares')
    ...

Podemos solucionar eso. Cambie la clase Validator de nivel superior para incluir un método __set_name__() como este:

# validate.py

class Validator:
    def __init__(self, name=None):
        self.name = name

    def __set_name__(self, cls, name):
        self.name = name

    @classmethod
    def check(cls, value):
        return value

    def __set__(self, instance, value):
        instance.__dict__[self.name] = self.check(value)

Ahora, intente reescribir su clase Stock para que se vea así:

class Stock:
    name   = String()
    shares = PositiveInteger()
    price  = PositiveFloat()

    def __init__(self,name,shares,price):
        self.name = name
        self.shares = shares
        self.price = price

Ah, mucho mejor. Sin embargo, tenga en cuenta que esta capacidad para establecer el nombre es una característica de Python 3.6. No funcionará en versiones anteriores.
