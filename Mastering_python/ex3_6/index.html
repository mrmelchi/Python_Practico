Objetivos:

Archivos creados: Ninguno

Archivos modificados: stock.py

(a) Mejorar la salida para representar objetos

Todos los objetos de Python tienen dos representaciones de cadena. La primera representación se crea mediante la conversión de cadena a través de str() (que se llama mediante print). La representación de cadena suele ser una versión bien formateada del objeto pensada para humanos. La segunda representación es una representación de código del objeto creada por repr() (o simplemente al ver un valor en el shell interactivo). La representación del código normalmente muestra el código que debes escribir para obtener el objeto. Aquí hay un ejemplo que ilustra el uso de fechas:

>>> from datetime import date
>>> d = date(2008, 7, 5)
>>> print(d)            # usa str()
2008-07-05
>>> d                   # usa repr()
datetime.date(2008, 7, 5)
>>>

Existen varias técnicas para obtener la cadena repr() en la salida:

>>> print('La fecha es', repr(d))
La fecha es datetime.date(2008, 7, 5)
>>> print(f'La fecha es {d!r}')
La fecha es datetime.date(2008, 7, 5)
>>> print('La fecha es %r' % d)
La fecha es datetime.date(2008, 7, 5)
>>>

Modifique el objeto Stock que ha creado para que el método __repr__() produzca una salida más útil. Por ejemplo:

>>> from stock import Stock
>>> goog = Stock('GOOG', 100, 490.10)
>>> goog
Stock('GOOG', 100, 490.1)
>>>

Vea lo que sucede cuando lee una cartera de acciones y visualiza la lista resultante después de haber realizado estos cambios. Por ejemplo:

>>> import stock, reader
>>> portfolio = reader.read_csv_as_instances('Data/portfolio.csv', stock.Stock)
>>> portfolio
[Stock('AA', 100, 32.2), Stock('IBM', 50, 91.1), Stock('CAT', 150, 83.44), Stock('MSFT', 200, 51.23),
Stock('GE', 95, 40.37), Stock('MSFT', 50, 65.1), Stock('IBM', 100, 70.44)]
>>>

(b) Hacer que los objetos sean comparables

¿Qué sucede si crea dos objetos Stock idénticos e intenta compararlos? Descubra:

>>> a = stock.Stock('GOOG', 100, 490.1)
>>> b = stock.Stock('GOOG', 100, 490.1)
>>> a == b
False
>>>

Puede solucionar este problema dándole a la clase Stock un método __eq__(). Por ejemplo:

class Stock:
...
def __eq__(self, other):
    return isinstance(other, Stock) and ((self.name, self.shares, self.price) ==
(other.name, other.shares, other.price))
...

Haga este cambio e intente comparar dos objetos nuevamente.

(c) Un administrador de contexto

En el Ejercicio 3.5, hizo posible que los usuarios crearan tablas con un formato agradable. Por ejemplo:

>>> from tableformat import create_formatter, print_table
>>> formatter = create_formatter('text')
>>> print_table(portfolio, ['name','shares','price'], formatter)
     name     shares      price 
---------- ---------- ---------- 
        AA        100       32.2
       IBM         50       91.1
       CAT        150      83.44
      MSFT        200      51.23
        GE         95      40.37
      MSFT         50       65.1
       IBM        100      70.44
>>>

Un problema con el código es que todas las tablas se imprimen en la salida estándar (sys.stdout). Supongamos que desea redirigir la salida a un archivo o a otra ubicación. En general, puede modificar todo el código de formato de tabla para permitir un archivo de salida diferente. Sin embargo, en caso de urgencia, también puede resolver esto con un administrador de contexto.

Defina el siguiente administrador de contexto:

>>> import sys
>>> class redirect_stdout:
        def __init__(self, out_file):
            self.out_file = out_file
        def __enter__(self):
            self.stdout = sys.stdout
            sys.stdout = self.out_file
            return self.out_file
        def __exit__(self, ty, val, tb):
            sys.stdout = self.stdout

Este administrador de contexto funciona creando un parche temporal en sys.stdout para hacer que toda la salida se redirija a un archivo diferente. Al salir, el parche se revierte. Pruébelo:

>>> from tableformat import create_formatter, print_table
>>> formatter = create_formatter('text')
>>> with redirect_stdout(open('out.txt', 'w')) as file:
        print_table(portfolio, ['name','shares','price'], formatter)

>>> # Inspeccione el archivo
print(open('out.txt').read())
     name     shares      price 
---------- ---------- ---------- 
        AA        100       32.2
       IBM         50       91.1
       CAT        150      83.44
      MSFT        200      51.23
        GE         95      40.37
      MSFT         50       65.1
       IBM        100      70.44
>>>
