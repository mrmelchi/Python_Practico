Ejercicio 6.3

Objetivos:

  • Aprender a inspeccionar el funcionamiento interno de las funciones

Archivos modificados: structure.py

(a) Inspección de funciones

Defina una función simple:

>>> def add(x,y):
       'Suma dos elementos'
       return x+y

>>>

Ejecute dir() en la función para ver sus atributos.

>>> dir(add)
... observe el resultado...
>>>

Obtenga información básica como el nombre de la función, el nombre del módulo que la define y la cadena de documentación.

>>> add.__name__
'add'
>>> add.__module__
'__main__'
>>> add.__doc__
'Suma dos elementos'
>>>

El atributo __code__ de una función contiene información de bajo nivel sobre la implementación de la función. Intente analizarlo y determinar el número de argumentos necesarios y los nombres de las variables locales.

(b) Uso del módulo inspect

Utilice el módulo inspect para obtener información de llamada a la función:

>>> import inspect
>>> sig = inspect.signature(add)
>>> sig
<Signature (x, y)>
>>> sig.parameters
mappingproxy(OrderedDict([('x', <Parameter "x">), ('y', <Parameter "y">)]))
>>> tuple(sig.parameters)
('x', 'y')
>>>

(c) Ensamblando todo

En el Ejercicio 6.1, creó una clase Structure que definía los métodos __init__(), __setattr__() y __repr__() generalizados. Esa clase requería que el usuario definiera una variable de clase _fields como esta:

class Stock(Structure):
    _fields = ('name','shares','price')

El problema con esta clase es que la función __init__() no tenía una firma de argumento útil para la ayuda y el paso de argumentos de palabras clave. En el Ejercicio 6.2, se utilizó un truco astuto con una función especial self._init(). Por ejemplo:

class Stock(Structure):
    _fields = ('name', 'shares', 'price')
    def __init__(self, name, shares, price):
        self._init()
    ...

Esto proporcionó una firma útil, pero ahora la clase es simplemente extraña porque el usuario debe proporcionar tanto la variable _fields como el método __init__().

Su tarea consiste en eliminar la variable _fields mediante técnicas de inspección de funciones. Primero, observe que puede obtener la firma del argumento Stock de la siguiente manera:

>>> import inspect
>>> sig = inspect.signature(Stock)
>>> tuple(sig.parameters)
('name', 'shares', 'price')
>>>

Quizás podría establecer la variable _fields a partir de la firma del argumento de __init__(). Agregue un método de clase set_fields(cls) a Structure que inspeccione la función __init__() y establezca la variable _fields según corresponda. Deberías usar tu nueva función así:

class Stock(Structure):
    def __init__(self, name, shares, price):
        self._init()

    ...

Stock.set_fields()

La clase resultante debería funcionar igual que antes:

>>> s = Stock(name='GOOG', shares=100, price=490.1)
>>> s
Stock('GOOG',100,490.1)
>>> s.shares = 50
>>> s.share = 50
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
  File "structure.py", line 12, in __setattr__
    raise AttributeError('No attribute %s' % name)
AttributeError: No attribute share
>>>

Verifica de nuevo la clase Stock ligeramente modificada con tus pruebas unitarias. Seguirá habiendo fallos, pero no debería haber cambios con respecto al ejercicio anterior.

En este punto, todo sigue siendo un poco complicado, pero estás progresando. Tienes una clase de estructura Stock con una función __init__() útil, una cadena de representación útil y el método __setattr__() restringe el conjunto de nombres de atributos. El paso adicional de tener que invocar set_fields() es un poco extraño, pero volveremos a ello.
