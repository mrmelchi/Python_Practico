Ejercicio 5.6

Objetivos:

  • Aprender a usar el módulo unittest de Python

Archivos creados: teststock.py

En este ejercicio, explorará la mecánica básica del uso de los módulos unittest de Python.

(a) Preliminares

En ejercicios anteriores, creó un archivo stock.py que contenía la clase Stock. En un archivo aparte, teststock.py, defina el siguiente código de prueba:

# teststock.py

import unittest
import stock

class TestStock(unittest.TestCase):
    def test_create(self):
        s = stock.Stock('GOOG', 100, 490.1)
        self.assertEqual(s.name, 'GOOG')
        self.assertEqual(s.shares, 100)
        self.assertEqual(s.price, 490.1)

if __name__ == '__main__':
    unittest.main()

Asegúrese de poder ejecutar el archivo:

 bash % python3 teststock.py
 .
 ------------------------------------------------------------------```
 Ran 1 tests in 0.001s

 OK
 bash %

(b) Pruebas unitarias

Usando el código de teststock.py como guía, amplíe la clase TestStock con pruebas para lo siguiente:

  • Pruebe que puede crear una Stock usando argumentos de palabra clave como Stock(name='GOOG',shares=100,price=490.1).
  • Pruebe que la propiedad cost devuelva un valor correcto.
  • Pruebe que el método sell() actualice correctamente las acciones.
  • Pruebe que el método de clase from_row() cree una nueva instancia a partir de datos correctos.
  • Pruebe que el método __repr__() cree una cadena de representación correcta.
  • Pruebe el método del operador de comparación __eq__().

(c) Pruebas unitarias con errores esperados

Supongamos que desea escribir una prueba unitaria que busque una excepción. Así es como puedes hacerlo:

class TestStock(unittest.TestCase):
    ...
    def test_bad_shares(self):
        s = stock.Stock('GOOG', 100, 490.1)
        with self.assertRaises(TypeError):
             s.shares = '50'
    ...

Usando esta prueba como guía, escribe pruebas unitarias para los siguientes modos de fallo:

  • Comprueba que al establecer shares en una cadena se genera un TypeError
  • Comprueba que al establecer shares en un número negativo se genera un ValueError
  • Comprueba que al establecer price en una cadena se genera un TypeError
  • Comprueba que al establecer price en un número negativo se genera un ValueError
  • Comprueba que al establecer un atributo share inexistente se genera un AttributeError

En total, deberías tener aproximadamente Docena de pruebas unitarias al terminar.

Nota importante

Para su uso posterior en el curso, necesitará los archivos stock.py y teststock.py completamente funcionales. Guarde su trabajo en curso si es necesario, pero le recomendamos encarecidamente copiar el código de Soluciones/5_6 si aún presenta problemas.

Usaremos el archivo teststock.py como herramienta para mejorar el código de Stock posteriormente. Es importante tenerlo a mano para asegurarse de que el nuevo código se comporte igual que el anterior.
