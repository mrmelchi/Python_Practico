Ejercicio 3.5

Objetivos:

  • Aprender a usar la herencia para escribir código extensible.
  • Ver un uso práctico de la herencia escribiendo un programa que debe generar datos en una variedad de formatos seleccionables por el usuario, como texto simple, CSV y HTML.

Archivos modificados: tableformat.py

Uno de los usos principales de las clases en Python es escribir código que se pueda extender o adaptar de varias maneras. Para ilustrarlo, en el Ejercicio 3.2 creó una función print_table() que generaba tablas. La utilizó para generar la salida de la lista portfolio. Por ejemplo:

>>> import stock
>>> import reader
>>> import tableformat
>>> portfolio = reader.read_csv_as_instances('Data/portfolio.csv', stock.Stock)
>>> tableformat.print_table(portfolio, ['name','shares','price'])
      name     shares      price
---------- ---------- ---------- 
        AA        100       32.2
       IBM         50       91.1
       CAT        150      83.44
      MSFT        200      51.23
        GE         95      40.37
      MSFT         50       65.1
       IBM        100      70.44
>>>

Supongamos que desea que la función print_table() pueda crear tablas en cualquier número de formatos de salida, como CSV, XML, HTML, Excel, etc. Intentando modificar La función de admitir todos esos formatos de salida a la vez sería complicada. Una mejor manera de hacerlo implica mover el código de formato relacionado con la salida a una clase y usar la herencia para implementar diferentes formatos de salida.

(a) Definición de una clase formateadora genérica

Agregue la siguiente definición de clase al archivo tableformat.py:

```python
class TableFormatter:
    def headings(self, headers):
        raise NotImplementedError()

    def row(self, rowdata):
        raise NotImplementedError()
```

Ahora, modifique la función print_table() para que acepte una instancia de TableFormatter e invoque métodos en ella para producir un resultado:

def print_table(records, fields, formatter):
    formatter.headings(fields)
    for r in records:
        rowdata = [getattr(r, fieldname) for fieldname in fields]
        formatter.row(rowdata)

Estas dos clases están pensadas para usarse juntas. Por ejemplo:

>>> import stock, reader, tableformat
>>> portfolio = reader.read_csv_as_instances('Data/portfolio.csv', stock.Stock)
>>> formatter = tableformat.TableFormatter()
>>> tableformat.print_table(portfolio, ['name', 'shares', 'price'], formatter)
Traceback (most recent call last):
...
NotImplementedError
>>>

Por ahora, no hace nada interesante. Lo solucionarás en la siguiente sección.

(b) Implementar un formateador concreto

El TableFormatter no está pensado para usarse por sí solo. En cambio, es simplemente una base u otras clases que implementarán el formato. Agregue la siguiente clase a tableformat.py:

class TextTableFormatter(TableFormatter):
    def headings(self, headers):
        print(' '.join('%10s' % h for h in headers))
        print(('-'*10 + ' ')*len(headers))

    def row(self, rowdata):
        print(' '.join('%10s' % d for d in rowdata))

Ahora, use su nueva clase de la siguiente manera:

>>> import stock, reader, tableformat
>>> portfolio = reader.read_csv_as_instances('Data/portfolio.csv', stock.Stock)
>>> formatter = tableformat.TextTableFormatter()
>>> tableformat.print_table(portfolio, ['name','shares','price'], formatter)
     name     shares      price
---------- ---------- ---------- 
        AA        100       32.2
       IBM         50       91.1
       CAT        150      83.44
      MSFT        200      51.23
        GE         95      40.37
      MSFT         50       65.1
       IBM        100      70.44
>>>

(c) Adición de más implementaciones

Cree una clase CSVTableFormatter que permita generar la salida en formato CSV:

>>> import stock, reader, tableformat
>>> portfolio = reader.read_csv_as_instances('Data/portfolio.csv', stock.Stock)
>>> formatter = tableformat.CSVTableFormatter()
>>> tableformat.print_table(portfolio, ['name','shares','price'], formatter)
name,shares,price
AA,100,32.2
IBM,50,91.1
CAT,150,83.44
MSFT,200,51.23
GE,95,40.37
MSFT,50,65.1
IBM,100,70.44
>>>

Cree una clase HTMLTableFormatter que genere una salida en formato HTML:

>>> import stock, reader, tableformat
>>> portfolio = reader.read_csv_as_instances('Data/portfolio.csv', stock.Stock)

(d) Facilitar la elección

Un problema con el uso de la herencia es la complejidad añadida de elegir las diferentes clases que se van a utilizar (por ejemplo, recordar los nombres, utilizar las instrucciones import correctas, etc.). Una función de fábrica puede simplificar esto. Agregue una función create_formatter() a su archivo tableformat.py que permita al usuario crear un formateador más fácilmente especificando un formato como 'text', 'csv' o 'html'. Por ejemplo:

>>> from tableformat import create_formatter, print_table
>>> formatter = create_formatter('html')
>>> print_table(portfolio, ['name','shares','price'], formatter)
<tr> <th>name</th> <th>shares</th> <th>price</th> </tr>
<tr> <td>AA</td> <td>100</td> <td>32.2</td> </tr>
<tr> <td>IBM</td> <td>50</td> <td>91.1</td> </tr>
<tr> <td>CAT</td> <td>150</td> <td>83.44</td> </tr>
<tr> <td>MSFT</td> <td>200</td> <td>51.23</td> </tr>
<tr> <td>GE</td> <td>95</td> <td>40.37</td> </tr>
<tr> <td>MSFT</td> <td>50</td> <td>65.1</td> </tr>
<tr> <td>IBM</td> <td>100</td> <td>70.44</td> </tr>
>>>

Discusión

La clase TableFormatter en este ejercicio es un ejemplo de algo conocido como una "Clase base abstracta". No es algo que esté destinado a usarse directamente. En cambio, sirve como una especie de especificación de interfaz para un componente del programa, en este caso los diversos formatos de salida. Básicamente, el código que produce la tabla se programará contra la clase base abstracta con la expectativa de que un usuario proporcione una implementación adecuada. Siempre que se hayan implementado todos los métodos requeridos, todo debería "funcionar" (crucemos los dedos).
