Ejercicio 7.1

Objetivos:

  • Aprender a definir funciones decoradoras simples.

Archivos creados: logcall.py

Archivos modificados: validate.py

(a) Tu primer decorador

Para empezar con los decoradores, escribe una función decoradora muy simple que simplemente muestre un mensaje cada vez que se llame a una función. Crea un archivo logcall.py y define la siguiente función:

# logcall.py

def logged(func):
    print('Añadiendo logging a', func.__name__)
    def wrapper(*args, **kwargs):
        print('Llamando a', func.__name__)
        return func(*args, **kwargs)
    return wrapper

Ahora, crea un archivo sample.py aparte y aplícalo a algunas definiciones de funciones:

# sample.py

from logcall import logged

@logged
def add(x,y):
    return x+y

@logged
def sub(x,y):
    return x-y

Prueba tu código de la siguiente manera:

>>> import sample
Añadiendo logging a add
Añadiendo logging a sub
>>> sample.add(3,4)
Llamando a add
7
>>> sample.sub(2,3)
Llamando a sub
-1
>>>

(b) Un decorador real

En el Ejercicio 6.5, creó una clase invocable ValidatedFunction que aplicaba anotaciones de tipo. Reescriba esta clase como una función decoradora llamada validated. Debería permitirte escribir código como este:

from validate import Integer, validated

@validated
def add(x: Integer, y:Integer) -> Integer:
    return x + y

@validated
def pow(x: Integer, y:Integer) -> Integer:
    return x ** y

Tu decorador debería intentar corregir las excepciones para que muestren información más útil, como se muestra. Además, el decorador @validated debería funcionar en las clases (no necesitas hacer nada especial).

class Stock:
    def __init__(self, name, shares, price):
        self.name = name
        self.shares = shares
        self.price = price

    @property
    def cost(self):
        return self.shares * self.price

    @validated
    def sell(self, nshares:PositiveInteger):
        self.shares -= nshares

Nota: Esta parte no requiere mucho código, pero hay muchos detalles de bajo nivel que requieren más detalle. La solución será prácticamente igual a la del Ejercicio 6.6. No dude en consultar el código de la solución.
